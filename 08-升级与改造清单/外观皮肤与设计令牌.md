# 外观皮肤与设计令牌（Vercel / Linear 极简无边框）

> 一句话：整套外观由 `12-源码照搬\外壳\renderer\styles.css` **末尾的一段「皮肤段」**统一接管 ——
> 靠设计令牌 + 阴影环表达层级，不再用 1px 实描边。回滚 = 删掉那一段。

- 落地日期：2026-11-10
- 风格来源：宿主给定「Vercel / Linear 极简无边框风（高级、干净）」：纯白或极浅灰底（#fafafa）、取消生硬边框、极淡阴影分层
- 改的文件：`renderer\styles.css`（+754 行皮肤段）、`renderer\renderer.js`（默认主题）、`外壳\main.js`（窗口底色）

## 1. 一句话口径（照着改就不会跑偏）

1. **画布 `#fafafa`，面板纯白**；层级只靠「阴影环 `0 0 0 1px rgba(16,24,40,.045)` + 极淡投影」表达，不用 `border`。
2. **颜色只留给状态**：`--ok / --warn / --err` 与场景身份图标；其余一律黑/灰/白。
3. **emoji 一律去色**（顶栏按钮、面板工具按钮、文件树图标）；悬停才提亮。网页版 AI 商标默认灰、悬停还原品牌色。
4. **一套皮肤两套主题**：浅色默认，深色是同一套结构的黑底版本，不是另写一份。
5. 皮肤段里的每条组件规则都带 `html[data-theme]` 前缀 —— 通吃两套主题，并且能压过前面 4900 行的历史覆盖。

## 4. 刻意不动的地方（动了会坏，别以为是漏改）

| 不能动 | 为什么 |
|---|---|
| `display / position / grid / flex` 结构 | 面板网格、拖拽换位、展开态定位都由 JS 按实际尺寸算 |
| `.panel` 展开动画只用 `top/left/width/height` | 面板内含 `<webview>`，祖先 `transform` 跟随不稳（`renderers.js:922` 注释） |
| 含 `.embed-wv` 的面板 `radius:0 / overflow:visible !important` | 内嵌 webview 的点击命中测试（`styles.css:4175`）：加圆角/裁切会让整块页面点不动 |
| `#grid` 的 `gap` | `packAutoGrid` 读 computed gap 排格（`renderers.js`） |
| 引擎内嵌页（对话 / 网页 AI / 本地网页） | 是 guest 文档，主题由 DSH 自己管；外壳不注入、不改写 |
| 启动页的 `position:fixed / z-index:30000 / flex 居中` | 三处 `!important` 是启动遮罩的硬约束，皮肤段只隐藏装饰伪元素 |

## 5. 怎么改 / 怎么回滚

- **微调**：直接在皮肤段对应节里改令牌或组件值；改完 `node 12-源码照搬\外壳\scripts\刷新面板.mjs all`，
  主窗口会带时间戳重拉 `styles.css`（`renderer.js` 的 `hotReloadRenderers`），不需要重启。
- **改默认主题**：`renderer.js` 的 `currentThemeMode()`；旧键 `guiTheme` 已迁到 `guiTheme.v2`（light / system 原样保留，dark 落回浅色）。
- **回滚整段**：删掉 `styles.css` 末尾「全量视觉重设计」整段 → 回到旧的深色霓虹皮肤（`git checkout` 亦可）。
- **只回滚启动页**：删掉第 ⑨ 节，其余保留。
- **新组件接入**：照第 1 节五条口径写，规则带 `html[data-theme]` 前缀，别写 `border`。

## 7. 最易误用点

1. **在皮肤段里写 `width/height/padding`** —— 面板标题栏、`.chart-panel-head` 的间距是按实测写死的，改大会把 K 线面板挤掉一行。
2. **给 `.panel` 加回 `border`** —— 阴影环已经是"边框"，再叠实线会变两层灰边。
3. **在皮肤段里改 `--r-md` 指望面板跟着变** —— 面板圆角写死 12px，`--r-md` 只服务菜单/卡片。
4. **以为改 `styles.css` 后不刷新就能看到** —— 主窗口要 `刷新面板.mjs`（或点 ⟳）才会带时间戳重拉 CSS。
5. **把 emoji 换成彩色图标** —— 与第 1 节口径冲突，整屏会重新"变花"。
