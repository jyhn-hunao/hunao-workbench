> **2026-11-21 进度**：阶段 A 的第一段已落地——`build` 段 + NSIS 配置进了 `外壳\package.json`；首启缺引擎时启动页出新按钮「⬇ 下载引擎」，主进程按 `机器配置.json` / `外壳\引擎源.json` 的下载源做「下载 → sha256 校验 → 解包 → 整目录替换 → 起引擎」。**下载源（url + sha256）仍未填**，所以现在打出来的安装包还装不出能用：干净机首启会停在「下载源未配置」。阶段 B（向导 / 数据目录 / 首绑回写）未动。

## 0. 做到什么才算「安装包」

1. 一个安装器（Windows `.exe`）：双击装，不装 Node、不装 npm、不手动放引擎。
2. 首次启动向导：机器配置 7 组（`workbenchRoot` / `repoRoot` / `codeRoot` / `ports` / `nodeExe` / `engineVersion` / `projects`）+ 端口 + 项目登记，全部落 `机器配置.json`。
3. 装完能跑：至少默认场景 + 1 个 AI 面板能切到会话（`sessionId` 自动建、自动回写，用户不碰）。
4. 数据与程序分离：数据目录可在向导里选，默认用户目录；卸载时可选保留。
5. 可升级 / 可回退：接现有 `引擎更新.mjs`（prepare / apply / rollback）。
6. 卸载干净：进程、端口、计划任务、开机项都清；数据按用户选择。
7. 签名：未签名安装器会被 SmartScreen 拦，内测可自签、对外需证书。

## 2.1 已落地（2026-11-21）

**首启下载链路**（`外壳\引擎引导.js`，只用 Node 内置模块，**不依赖 pnpm / 本机 node**）

- 检测两套布局（`lib/bin.js` / `apps/cli/lib/bin.js`）；打包版缺 `node_modules` 判「半截产物」，不当已就位。
- 下载源优先级：`env`（`DSH_ENGINE_URL` / `DSH_ENGINE_SHA256`）> `机器配置.json` 的 `engine.source` > `外壳\引擎源.json`；sha256 不是 64 位十六进制**直接拒装**。
- 下载支持 http/https（302 最多 5 跳）、`file://` 与本机路径；边下边算 sha256；进度经 `boot:progress` 回启动页。
- 解包到同级 `staging` → 验入口 → 旧引擎改名 `.bak-<时间>` → 新目录 rename → 写 `.engine.json` → 删备份；任一步失败回滚。
- 启动页：缺引擎时只留「⬇ 下载引擎（约 500 MB）」一个动作，下载中隐藏「立即进入」，失败把原因写到 detail 行并可重下。

**验证（本机 2026-11-21）**

| 用例 | 结果 |
|---|---|

| 二次 `--force` 换 v2 | 通过：旧目录清掉，只剩新引擎，无 `.bak` 残留 |

静态：`测试.mjs` 全过（warning 2，属存量）；`未定义检查` 0 命中。`功能台 --verify` 102 个动作：静态项通过；5 个只读项在本机退出 1（chat-archive / publish-check / env-selftest / engine-after ×2），属本机环境/配置差异，需单独排查。

## 3. 推荐路线（三步，不追求一次到位）

**阶段 A：能装**
- electron-builder + NSIS，per-user 安装；先**不随引擎**。
- 首启检测引擎：没有就引导下载官方包，校验 sha256 后落到 `引擎\`；两套布局都认（`lib/bin.js` / `apps/cli/lib/bin.js`）。

**阶段 B：装完能跑**
- 向导收 7 组 → 写 `机器配置.json` → 跑 `环境适配 --apply`。
- 自动为默认场景建会话并回写 `sessionId` → 打开默认场景。
- 验收：干净 Windows 上，从双击到 AI 面板回第一句话，≤10 分钟。

**阶段 C：可维护**
- 接引擎更新 / 回退；卸载保留数据；签名；自动更新。
- 验收：升级不丢数据，回退能回上一版引擎。

**不做（明确排除）**
- MSI（NSIS 足够）；内置两套 Node；把源码版引擎（数 GB）塞进安装包；安装器里生成 `sessionId`。

## 4. 验收（Definition of Done）

1. **干净机**：无 Node / 无 npm / 无引擎，双击安装 → 默认场景 AI 面板能对话。
2. **卸载**：进程、端口、计划任务、开机项清空；数据按选择保留或删除。
3. **升级**：旧数据不丢；引擎可回退；`sessions.mjs --check` 仍全过。
4. **自检**：安装后布局下 `自检.mjs` exit 0（`nodeExe` 指随包 node、引擎两布局识别、端口无冲突）。

## 5. 与现有硬规则的关系

- 端口：仍 `env > 机器配置.json > 默认`；⛔ 安装器不改脚本里的端口字面量。
- 会话：`sessionId` 仍只由 `建会话` / `换会话` 回写；⛔ 向导、配置字典、模板渲染都不生成。
- 文档：安装器交付前，README / 新手必读保留「当前源码版」用法；交付后再删掉「照抄必失败」的警告，改成「装完即用 + 高级配置」。
