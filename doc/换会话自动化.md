# 换会话 · 自动化机制（2026-11-12）

> 一句话：点一下「换会话」= 一条链路自动跑完「写交接 → 建新会话 → 改绑 → 归档旧 → 记忆重盖章 → 自检指针 → 只重载本面板」；
> 压力到阈值且会话空闲时，这条路自己跑。任何一步回写失败，旧会话都**不会被归档**。
>
> 换会话不只是"换一条会话"：它会改掉会话 id，而会话 id 是记忆系统的主键（json / 定位卡 / 身份索引 / 身份卡四处都引它），
> 所以这条链路必须把**记忆联动**一起做完，见第二节。

涉及文件（都在 `12-源码照搬/` 下）：

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 主进程 | `外壳/main.js` | `harness:rotate` IPC、按 sceneId 互斥、进程树超时、阶段推送、到期自动触发、JSONL 日志 |
| 桥 | `外壳/preload.js` | `harnessRotate` / `onRotateProgress` / `onRotated` |
| 界面 | `外壳/renderer/renderers.js` | 按钮（标签显示阶段）、成功后自己重载本面板、失败 toast 带回滚说明 |
| 编排 | `外壳/scripts/换会话.mjs` | 预检 → 轮换（`--defer-archive`）→ 定位卡 → 归档 → **记忆重盖章** → 指针自检 |
| 原子操作 | `外壳/scripts/sessions.mjs` | 建会话 / 改名 / 改绑 json 与名册 / seed 写记忆接力点 / `--check` |
| 归档 | `外壳/scripts/归档会话.mjs` | 只做归档（名字带 `YYYY-MM-DD HHmm`，同日多次不重名） |
| 交接 | `工具/交接并换会话.mjs` | 从 transcript 摘录，写**面板级**交接 md；§〇 只写指针行（绝对路径） |

## 一、阶段机（1/3 → 2/3 → 3/3）

脚本按行打 `P|<步>|<名称> · <说明>`，主进程解析后推 `harness:rotate-progress`；界面把按钮标签改成 `换会话 1/3`…，结果一律顶栏 toast（面板上不放会消失的文字）。

```
1/3 交接     读旧会话 transcript → 摘最近 4 轮业务轮（元讨论单列）→ 写 面板交接\<panelId>.md
             旧版先 copy 成 <panelId>-上一版.md（只留一代）；无业务轮次也落占位文件
             §〇 只更新本面板的指针行（绝对路径），第 2–5 节原样保留
2/3 建会话   sessions.mjs --rotate ... --defer-archive：建新、改名、改绑 json 与名册（旧会话此时不动）
             --check 不判整次失败：只 warn，绑定已生效就不回滚
             seed：给新会话写一条开场消息，把"记忆接力点"（绝对路径）列清，然后立刻打断
3/3 换绑     回写定位卡 scenarios\<场景>-context.md 的对应面板行
             → 归档会话.mjs <旧 id> --go（真归档，此时前面全部成功了）
             → 场景记忆.mjs stamp：身份卡 / 场景画像按新会话重盖章（记忆联动）
             → 自检 §〇 指针指向的文件是否真存在
             → 渲染层自己 wv.reload()（只重载本面板）
```

脚本收尾打 `NEWID: <session-id>` / `ELAPSED: <秒>`，失败打 `✗ ...` 并非 0 退出。

## 二、记忆联动（换会话 = 记忆接力，不是"换条空会话"）

会话 id 一改，下面这些记忆文件里的"我绑哪条会话"就全部过期。链路必须逐项对齐：

| 记忆 | 路径（`引擎数据\.dsh\` 下） | 谁维护 | 换会话时做什么 |
| --- | --- | --- | --- |
| 身份卡 | `场景记忆\<场景>\身份卡.md` | `场景记忆.mjs stamp` 全量生成 | **换完必须重 stamp**，否则 check 报「卡指纹过期」 |
| 场景画像 | `场景记忆\<场景>\场景画像.md` | 同上 | 同上（与身份卡同一次 stamp） |
| 场景 §〇 | `场景记忆\<场景>\场景私有记忆.md` | 交接脚本只写第 1 节指针 | 第 1 节留「每面板一行」，第 2–5 节不动 |
| 面板交接 | `场景记忆\<场景>\面板交接\<panelId>.md` | 交接脚本 | 每面板各一份，旧版留一代，空轮次也落占位 |
| 项目薄卡 | `场景记忆\<场景>\项目记忆\<项目>.md` | 长期记忆（人 / 技能维护） | **不动**，只在面板交接里给读取路径 |
| 共享注册表 | `场景记忆\_共享记忆\项目.json` | 长期记忆 | **不动**，只在面板交接里给读取路径 |
| 定位卡 | `外壳\scenarios\<场景>-context.md` | 场景工具 / 项目切换 | 回写该面板那一行的会话 id |
| 场景身份索引 | `外壳\scenarios\_场景身份索引.md` | 人 / AI 维护 | `sessions.mjs` 回写「同一行既有旧 id 又有面板 id」那行 |
| seed（新会话开场消息） | 引擎会话内 | `sessions.mjs` | 列出上述文件的**绝对路径**，让新会话知道接力点在哪 |

**三条硬规矩**

1. **指针一律绝对路径**。各面板 cwd 不同（`cd-ai` = 项目根、`cd-ai-home` = `12-源码照搬\工作区`），
   相对 `12-源码照搬` 的路径两边都解析不到 —— 2026-11-12 实测就是死链，新会话照指针找不到交接。
2. **长期记忆只追加**。§五 坑与决策、§八 项目索引、项目薄卡都是长期结论；换会话产出的只是"这一段的摘要"，不得覆盖。
3. **先归档、再盖章**。stamp 必须在场景 json 已改成新 id 之后跑，否则盖出来的还是旧绑定。

**刻意没做的事**：本次会话产生的新知识（新坑、新决策、项目现状变化）**没有**自动写进 §五 / 项目薄卡。
规则抽取（"不是…而是""按…为准"这类句式）误判率高，写错长期记忆比漏写更难修。
现在的处理是：面板交接的「记忆联动」小节告诉新会话该读哪些长期记忆，由它在第一条真实指令时按需补；要强制沉淀就明确说一句。

## 三、回滚与自愈语义

| 失败点 | 结果 | 现场 |
| --- | --- | --- |
| 预检引擎不可达（`http://127.0.0.1:3083/` 4 秒超时） | 直接退出 3，不白等 | 旧会话、绑定、定位卡全部原样 |
| 交接写失败 | 不继续轮换 | 旧会话在；§〇 原样（未写就不改） |
| 建会话/改名/改绑失败 | 退出非 0 | 旧会话**未归档**，面板仍指旧会话，可直接再点重试 |
| `--check` 未通过但绑定已生效 | 只 warn | 面板可用；明细在输出 `✗` 行 |
| 定位卡回写失败 | 退出非 0 | json 已指新会话，定位卡落后 ⇒ 下次 `--check` 会报出来，可再点修 |
| 归档失败 | 退出非 0 但**新会话已生效** | toast 写"归档失败"，旧会话留在列表里，可手工 `归档会话.mjs` |
| 重盖章失败 | 退出 0 + WARN | 面板已可用；跑一次 `场景记忆.mjs stamp` 即补 |
| 超时 | 主进程 240 秒杀**进程树**（脚本内 180 秒先自报） | 见日志 `ev=fail` + `reason` |

## 四、到期自动换会话

配置：`外壳\data\自动换会话.json`（首次运行自动生成）

```json
{ "enabled": true, "threshold": 88, "minTurns": 20, "idleMin": 10, "cooldownMin": 30 }
```

判据全部满足才动：压力 ≥ threshold（口径与 `sessions.mjs` 的 `pressures()` 一致）+ 轮次 ≥ minTurns + 会话文件空闲 ≥ idleMin 分钟 + 同面板距上次自动换 ≥ cooldownMin。

- 每 **5 分钟**扫一次，每次最多换**一个**面板（避免同时改多份场景 json）；跑着别的换会话时整轮跳过
- 成功广播 `harness:rotated`，对应面板自己 reload；开始时只 toast 一次，其余阶段不刷屏
- 不想被自动归档：`enabled: false`（无需重启，下一个 tick 读到就停）

## 五、命令（命令行等价操作）

```powershell
# 只写交接不轮换（验证记忆联动 / 手工补交接）
node 12-源码照搬\工具\交接并换会话.mjs --panel cd-ai --handoff-only

# 看计划（不动任何东西）
node 12-源码照搬\工具\交接并换会话.mjs --panel cd-ai --dry

# 完整换会话（命令行下没有渲染层，脚本会写 reload-panels.cmd 让壳全面板重载）
node 12-源码照搬\外壳\scripts\换会话.mjs cd-ai --go

# 记忆与绑定各查一次
node 12-源码照搬\工具\场景记忆.mjs check --场景 程序开发
node 12-源码照搬\外壳\scripts\sessions.mjs --check
```

GUI 内由主进程传 `DSH_ROTATE_SELF_RELOAD=0`，不写 reload cmd，只让渲染层重载本面板。

## 六、证据链

- `外壳\data\换会话日志.jsonl`：一行一个事件，字段 `ts / ev(start·done·fail·auto-trigger·auto-done·auto-fail·auto-crash·spawn-fail) / panel / scene / old / newId / code / stage / elapsed / warn / reason`；超过 1 MB 轮转为 `.prev`
- `场景记忆\<场景>\归档\`：每次交接把旧版整份归档，可按时间回溯
- 面板交接文件头部记旧会话 id，归档后仍能顺着 id 找回旧 transcript

## 七、验收用例

| # | 场景 | 期望 |
| --- | --- | --- |
| 1 | 正常：引擎在跑，点 cd-ai「换会话」 | 按钮 1/3→2/3→3/3；toast "完成"；本面板重载后绑新会话；json / 定位卡 / 索引一致；身份卡 stamp 时间更新且会话 id 是新 id；旧会话已归档 |
| 2 | 边界：连点两次 | 第二次立刻 `code=busy` + toast，不会两份脚本同改 json |
| 3 | 边界：同场景两块 AI 面板各换一次 | §〇 第 1 节同时保留两行指针，两个 md 都在，互相不覆盖 |
| 4 | 边界：旧会话只有开场消息 | 落占位交接 md，指针可达，不覆盖上次真交接 |
| 5 | 异常：引擎没起 | 3 秒内失败，toast 写"引擎没在跑"；一切原样 |
| 6 | 自动：threshold 调到很低 | 空闲面板自动换，`auto-trigger` / `auto-done` 进 JSONL，只该面板重载 |

标注：交接链路、两面板指针共存、空轮次占位、§〇 字节与 `check` 都**已实跑验证**；完整一次真换会话（含归档）**未跑**（会归档真实会话，需你点头），主进程 / GUI 阶段标签需重启壳后验证。

## 八、最易误用点

- 别手工改 `scenarios/*.json` 的 `sessionId` 后不跑 `--check`：四处（json / 定位卡 / 身份索引 / 身份卡）必须同源
- 别把 `--defer-archive` 用到"只想建会话"的场合：它就是给换会话编排用的，单独跑会留下未归档的旧会话
- 关自动换会话要改 `enabled`，不是删文件（删了下一个 tick 会用默认值重建成 `enabled:true`）
- 面板交接是"面板级"，别再往 §〇 正文里手写整段交接（4 KB 红线一撞就换不动）
- 指针不要改回相对路径 —— 各面板 cwd 不同，相对路径必死
