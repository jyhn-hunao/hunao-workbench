# 工具启用价值评估（DSH 工具包）

> 2026-11-12 · 依据：`12-源码照搬\引擎\node_modules\@deepseek-ai\` 实际安装的 `dsh-tool-*` 包 + `dsh-base\cordis.patch.yml` 启用名单 + 各包 `locale\zh.json`。
> 本报告**不改变任何启用状态**，等拍板。启停方式：在 `引擎数据\.dsh\profiles\web\cordis.patch.yml` 里按包名加/改一行（或让「程序开发」会话改）。

## 0. 口径与计数

- 已安装工具包：**21 个**；默认 profile（dsh-base 的 patch）实际启用且装得上的：**12 个**；未启用：**9 个**。
- 每轮工具定义开销实测：当前 12 个工具合计 **7205 token**（来源：`storages\session_projcache\sessions\*.json` 的 `contextBreakdown.breakdown.toolsTokens`，2026-11-12 采样）。⇒ 平均 ≈ 600 token/工具/轮，按 schema 复杂度 300–800 估。
- 注意：工具定义**每一轮都随 prompt 重发**，开 3 个 ≈ 每轮多 1.5–2 K；长会话里它的成本会按轮数放大。

## 1. 未启用清单与判断

| 包 | 一句话用途（locale 原文摘要） | 对哪些场景有用 | 依赖 / 凭据 | 估 token/轮 | 结论 |
|---|---|---|---|---|---|
| `dsh-tool-ask-user` | 需要补充信息或做选择时向用户提问（结构化选项） | **全部场景**，尤其程序开发/命令（确认口径、选方案） | 无外部服务 | ~300 | **建议启用**：与「逐个提问、先确认」的偏好一致，比聊天里追问更省一轮 |
| `dsh-tool-present` | 把工作区文件标记为「本轮交付」 | 程序开发、命令、B站（交付文档/图/视频清单） | 无 | ~350 | **建议启用**：交付物能在界面上被明确列出，用户不用翻路径 |
| `dsh-tool-schedule` | 建/查/改/删提醒（4 个工具） | **自我复盘、命令、工作台自身**（收工提醒、定时复查） | 无（走 Host ctx.schedule） | ~500 | **建议启用**：定时类需求（「明早提醒我」）目前只能靠人记 |
| `dsh-tool-pwsh-persistent` | 保留状态的 PowerShell 会话里连续执行命令 | **程序开发、本地电脑**（多步诊断/构建） | 本机 PowerShell；无外部凭据 | ~400 | **可用但看场景**：多步命令能省 token，但会扩大会话状态；当前非持久版够用 |
| `dsh-tool-bash-persistent` | 保留状态的 Bash 会话 | 基本用不到（本机 Windows，Bash 只在 Git Bash 场景） | 需要 Bash/PTY | ~400 | **建议保持关闭**：与 pwsh 功能重叠，本机用不上 |
| `dsh-tool-str-replace-editor` | 视图/创建/字面替换/按行插入（另一套文件编辑） | 程序开发（但已有 fs + edit） | 依赖沙箱与 fs | ~600 | **建议保持关闭**：与 `fs` 能力重叠，纯增 token 与误用面 |
| `dsh-tool-cordis` | 只读查询 Harness 插件 API（开发插件时用） | 只有「改 DSH 插件」时需要 | 需要 cordis 运行时 | ~400 | **建议保持关闭**：本项目不改引擎/插件 |
| `dsh-tool-ralph` | 围绕同一目标逐轮起新子智能体并传上一轮摘要 | 长周期无人值守迭代（本项目无此流程） | 依赖 subagent + workflow | ~500 | **建议保持关闭**：实验性，和现有 subagent 派单重复 |
| `dsh-tool-workspace-dependencies` | 给出内置 Python/Node/pnpm 的绝对路径 | 需要固定运行时路径的自动化 | 需要引擎自带 payload | ~300 | **建议保持关闭**：本机运行时已固定，用不到 |

## 2. 结论

- **建议启用 3 个**：`ask-user`、`present`、`schedule` ≈ 每轮 +1.2 K token，换来「结构化确认 + 交付可见 + 定时提醒」。
- **可用但看场景 1 个**：`pwsh-persistent`（多步命令多时再开）。
- **建议保持关闭 5 个**：`bash-persistent`、`str-replace-editor`、`cordis`、`ralph`、`workspace-dependencies`（与现有能力重叠或本项目无场景）。
- 若只开 1 个：优先 `ask-user`——它直接减少来回追问的轮数（省下来的通常多于它自身定义的开销）。

## 3. 怎么落地（拍板后）

1. 在 `引擎数据\.dsh\profiles\web\cordis.patch.yml` 追加（示例，按 id 与包名）：
   ```yaml
   - id: tool-ask-user
     name: "@deepseek-ai/dsh-tool-ask-user"
   ```
2. 重启引擎（关掉工作台再开），`node 12-源码照搬\外壳\工具清单.js` 应显示该包不再带「未启用」；
3. 验证：工具面板出现该工具，且 `contextBreakdown.toolsTokens` 相应上升（记录前后值）。

> 数据来源：安装目录、patch 文件、`locale\zh.json`、projcache 的 toolsTokens。除 toolsTokens 外均为静态读取；token 为单次采样 + 按 schema 复杂度的区间估计（**静态推断**）。
