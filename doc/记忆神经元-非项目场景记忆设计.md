## 2. 总规则（按场景定轴）

1. **轴由这个场景怎么干活决定**：人格是人 + 时间 + 承诺，社交是人 × 通道，本地电脑是机器 × 时间 × 结果，复盘是主题 × 教训，生活是作息 × 内容。
2. 每个场景一进下钻，先看到 3–7 个页签（常驻文字入口），顺序按重要性，不按字母；空页不出现，不显示 0。
3. 空就照实说（「索引就绪 · 还没有条目」/「她是谁 = 人格卡」），缺就给建索引入口，不画假点、不猜数字。
4. 不把程序开发的「项目 / 知识点」概念搬到别的场景。
5. 派生条目的数字必须来自事实源（`社交关系.json`、`pc-cleanup-*.json`），读不到就不显示，不手写。

### 6.1 自主记忆链路（A1–A5，2026-11-25）

> 目标：记忆不能靠人敲命令。人只负责聊天，采集、提炼、索引、刷新都在后台完成。

| 编号 | 机制 | 落点 | 频率 / 触发 | 关掉的方式 |
| --- | --- | --- | --- | --- |
| A1 | **面板对话自动采集**：当前绑定会话 + 同名旧会话（换会话归档后的尾段也补扫），按会话游标增量配对「他说 → 她答」，跳过注入块 / 回执 / 通道信封，按天追加 `对话\YYYY-MM-DD-面板.md` | 新工具 `工具\自主记忆.mjs`；外壳 `main.js` 的 `scheduleAutoCapture()` | 引擎就绪后 2 分钟起，每 10 分钟一轮；唤醒补跑 | 人格面板 ⚙ 设置 → 记忆 → 「记下聊过什么」关 |
| A2 | **通道往来自动采集**：QQ / 微信 / 飞书 的真人往来落进同一套 `对话` 记忆 | 复用 `工具\通道记忆.mjs`；外壳 `scheduleAutoChannelMemory()` | 5 分钟起，每 30 分钟一轮；唤醒补跑 | 同上 |

两条硬约束：

- **游标只前移到最后一个已收尾的回合**：末尾那条刚发出、还没回复的用户消息留到下一轮，避免「抓了一次没配上，以后永远从 224 往后看」。
- **写入失败不再等于整轮失败**：`人格记忆.mjs 写` 成功落盘后，即使场景还有别的自检问题也只提示、退出 0；`通道记忆` 不会把 4 条已写成的记忆误报成「4 条没写成」。
- **设置读不出来按关处理**：`memoryWriteOn()` 读人格设置异常时不再默认 `true`，本轮不采并记 `warnOnce`，避免用户关了记忆仍继续写。
- **采集失败可见**：`自主记忆 status` 上次有 `error` 时退出 1；采集途中写盘/转录/锁异常也会写 `status.error` 再退出；`自动巡检` 已把「自主记忆」列为第 8 项，失败会进 `巡检.json` / `自动维护.log` 并触发顶栏提示。

### 6.2 已知边界（还没做的）

| 边界 | 现状 | 影响 |
| --- | --- | --- |
| 只采人格面板 | `自主记忆` 只扫「胡闹的大肥鱼」面板（当前绑定 + 同名旧会话） | 程序开发 / 生活 / 记忆 / 自我复盘等场景面板的日常对话不自动进 `对话` 记忆；这些场景仍靠各自的场景记忆工具写 |
| 补写只补昨天 | 错过 23:00 后由下一次 tick 补昨天；更早的漏写不重放 | 只保证最近一天；连关机数天需要手动 `日记.mjs 写 --日` 逐天补 |
| 通道-only 昨天不补 | 补写条件看 `对话\<日期>-面板.md` 是否存在；只有 QQ/微信/飞书往来、没有面板对话的那天不补 | 通道内容仍在 `对话`，只是不生成日记 |
| 提炼覆盖率有限 | 一天只靠日记最多提炼 3 条记忆 + 2 条待办 | 当天话题多时，其余只留在原始 `对话`，不会自动进长期记忆 |
| 部分写入重复 | hash 与游标在所有 append 完成后才落盘 | 中途写文件失败时，下一次可能把已写过的对子再写一遍（低频） |
| 面板健康牌未做 | 人格面板顶栏副标题在采集失败时变红字并带失败摘要，成功恢复原文；没有独立健康页、没有历史曲线 | 能看到“当前挂了”，看不到连续失败次数和最近 7 天趋势 |

已修：

- **日记漏写**：`日记.mjs` 支持 `--日` 补写，自动调度在下一次 tick 补昨天；`人格记忆.mjs` 支持 `--日期`，候选记忆/待办也落在被补的那天。
- **并发写索引**：新增 `withLock`（`派发-公共.mjs`），`人格记忆 写` 与 `场景记忆 索引` 各用一把跨进程锁；正文文件仍各自独立，锁只护 `_索引.md` / `_近期.md` / 场景目录。
- **技术故障污染**：`自主记忆` 对回复里含 `DSH_TOKEN` / `server.log` / 拿不到 token / 派不出去 的段落整段剔除；整条都是故障就记一句「这轮在修工具」，保留同一回复里的正常话。
- **候选噪声**：日记 prompt 明确「记忆候选只写以后还会用到的事，空泛总结写（无）」；`splitCandidates` 过滤「基本没什么可记 / 各干各的 / 一切照旧」这类条目，并去掉标题前重复日期；`人格记忆` 待办按去虚词后的双字重合度 ≥0.55 拒写近似条目。补写实测产出的一条空泛记忆与两条重复待办已清掉。
- **一轮连发两条**：`pairsOf` 同一 `turn` 的多条真人消息合并，不再只留最后一句。
