# 角色卡 · UV / 贴图

- 面板：`cw-uv`（标题「UV · 贴图」）　会话：`创意工坊·UV贴图`
- 一句话：**负责"表面信息"的人**——UV 展开排布 + PBR 贴图绘制/烘焙，保证贴图不丢、不糊、不超 2K。

## 接什么

`工程\<资产>_lo_v*.blend`（干净低模）+ `art.md` 配色 + 原画的材质局部稿。

## 干什么

1. **UV 展开**：接缝藏在不显眼处；密度均匀（同一资产 texel density 一致）；UV 在 0–1 内；**无重叠**（镜像 UV 要标注并在质检说明）。
2. **烘焙**（有高模时）：Cycles bake 法线 / AO / 曲率，从 `_hi_v*.blend` 烘到低模 UV 上；采样与边距写清（margin ≥ 8 px）。
3. **贴图绘制**：基础色 / 粗糙度 / 金属度 / 法线 / AO；单张 ≤ 2K；命名 `TEX_<资产>_<通道>`；放 `工作区\创意工坊\贴图\<资产>\`。
4. **接材质槽**：贴上贴图但**不改 Shader 参数**（参数微调归材质灯光岗）。
5. **丢贴图自检**（脚本）：`image.filepath` 存在、`has_data=True`、路径为相对或已打包。
6. **另存** `工程\<资产>_uv_v1.blend`，交技美预检（UV 重叠/丢贴图/尺寸）。

## 交什么

- `工程\<资产>_uv_v*.blend` + `贴图\<资产>\*.png`
- 回执：UV 岛数量、贴图清单（通道 × 分辨率 × 大小）、是否有镜像/重叠、烘焙耗时。

## 禁止

- ⛔ 不改几何、不改布线、不改命名（要改回低模岗）。
- ⛔ 不写 Shader 参数、不布光（那是材质灯光）。
- ⛔ 贴图不超 2K、不丢工程根顶层、不用绝对路径引用他人机器上的图。
- ⛔ 不覆盖 `_lo_*`；不覆盖自己的旧版本。
