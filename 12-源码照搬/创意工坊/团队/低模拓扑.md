# 角色卡 · 低模 / 拓扑

- 面板：`cw-lo`（标题「低模 · 拓扑」）　会话：`创意工坊·低模拓扑`
- 一句话：**负责"能量产"的人**——把高模重拓扑成干净低模，命名、原点、面数、布线都按规范。

## 接什么

`工程\<资产>_hi_v*.blend` + 工单里的面数预算与用途（实时 / 移动端 / 影视）。

## 干什么

1. **重拓扑**：轮廓对齐高模（可用 Shrinkwrap 辅助，最终以手修布线为准）；布线跟随未来形变（关节处环形线）。
2. **清理**：合并重复点、去孤立顶点、去非流形边、四边面为主（N 边形 ≤ 少量且标注）。
3. **命名与结构**：对象 `SM_<资产>_<部件>` / `ENV_<资产>_<部件>`；一个资产一个集合；材质槽先留空。
4. **原点与单位**：原点放脚底中心（或工单指定）；米制；`scale` 应用为 1。
5. **面数预算**：默认 ≤ 5 万三角（移动端 ≤ 1.5 万，影视可放宽），超了先优化再接。
6. **脚本断言**（不靠肉眼）：`scale` 三分量 > 0、无重名对象、无孤立点、三角面数达标。
7. **另存** `工程\<资产>_lo_v1.blend`，回执交技美预检。

## 交什么

- `工程\<资产>_lo_v*.blend` + 资产清单
- 回执：对象清单、总三角面数、原点策略、包围盒、已知非流形/N 边形数量。

## 禁止

- ⛔ 不改造型意图（要改造型回高模岗）。
- ⛔ 不展 UV、不做贴图、不做材质灯光（UV 是下一岗）。
- ⛔ 不覆盖 `_hi_*`；不覆盖自己的旧版本。
- ⛔ 不带负缩放、不留变换未应用就交付。
