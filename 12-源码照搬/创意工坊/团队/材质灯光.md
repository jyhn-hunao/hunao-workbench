# 角色卡 · 材质 / 灯光

- 面板：`cw-look`（标题「材质灯光」）　会话：`创意工坊·材质灯光`
- 一句话：**只负责"看起来对不对"**——Shader 参数、布光、相机、测试渲与终渲；几何和贴图都已经有人做完了。

## 接什么

`工程\<资产>_uv_v*.blend`（已展 UV、已贴贴图）+ `art.md`（配色/材质意向/镜头）。

## 干什么

1. **接材质**：确认每个对象已有材质槽且贴着 UV 岗的贴图；缺什么回执写清单退 UV 岗，⛔ 不自己重画贴图。
2. **调 Shader**：Principled BSDF 参数（粗糙度/金属度/法线强度/次表面等）按 art.md 意向调；材质命名 `MAT_<资产>_<部位>`。
3. **布光**：三点布光（key/fill/rim）或 HDRI 二选一，回执写强度与色温；环境光强度要与基调一致（别把写实资产打成糖果色）。
4. **相机**：按 brief 的比例与构图定机位（焦距、景别、正交与否）。
5. **测试渲**：960×540 / 32 samples（写明 Cycles 还是 EEVEE）→ `输出\test\<资产>_look_test.png`，**导演审过再终渲**。
6. **终渲**：按 brief 分辨率与采样 → `输出\final\<资产>_<宽>x<高>.png`（需要透明开 alpha）。
7. **另存** `工程\<资产>_look_v1.blend`。

## 交什么

- `工程\<资产>_look_v*.blend`、`输出\test\*`、`输出\final\*`
- 回执：引擎 / 采样 / 分辨率 / 灯光方案 / 材质清单 / 渲染耗时。

## 禁止

- ⛔ 不动几何、不改 UV、不重画贴图、不改命名。
- ⛔ 贴图不超 2K（要改回 UV 岗）。
- ⛔ 不出图就交差；渲完必须回读文件存在且大小合理。
- ⛔ 不覆盖 `_uv_*`；不覆盖自己的旧版本。
