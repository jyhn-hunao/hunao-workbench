# 使用说明（公开模板）

## 一、它是什么

一套装在你自己电脑上的 AI 工作台：5 个场景、6 个 AI 面板、记忆写在本地文件里。
需要你自己的 DSH（DSH 引擎）引擎——本包**不带引擎**。

## 二、第一次用

```powershell
cd 外壳
npm install
cd ..
双击 启动.vbs        # 端口 3083，不动你原有的 3080
```

然后给每个场景建会话：

```powershell
node 外壳\scripts\建会话.mjs --title "命令"
node 外壳\scripts\建会话.mjs --title "B站"
node 外壳\scripts\建会话.mjs --title "自我复盘"
node 外壳\scripts\建会话.mjs --title "本地电脑"
# 把每个命令最后一行打印的 sessionId 写回 外壳\scenarios\<场景>.json 的 sessionId / sessionTitle
node 外壳\scripts\sessions.mjs --check
```

## 三、日常

| 想干什么 | 怎么做 |
|---|---|
| 加场景 | 复制 `外壳\scenarios\` 里一个 json，改 `id`/`name`/`panels`；同步 `_场景身份索引.md`；跑 `建会话.mjs`；顶栏 ⟳ |
| 改面板 | 改 `外壳\scenarios\<场景>.json`，顶栏 ⟳ 热更新 |
| 备份界面 | `node 外壳\scripts\backup-gui.mjs` |
| 还原界面 | `node 外壳\scripts\restore-gui.mjs` |
| 打包带走 | `node 工具\封装.mjs --out <盘根>:\发布` |
| 出包前自检 | `node 工具\发布前检查.mjs` |

## 四、记忆怎么用

- 每个场景的 AI 干完活，让它把结论写进该场景的 `场景私有记忆.md`（这一步仍然要它自己写）
- **换会话不用你手动跑交接**：点面板「换会话」会自动完成「写面板交接 → 建新 → 改绑场景 json / 定位卡 / 身份索引 → 归档旧 → 只重载本面板」；交接落在 `场景记忆\<场景>\面板交接\<面板id>.md`，§〇 里只留一行指针
- **换完会自动重盖身份卡**：会话 id 变了，身份卡 / 场景画像里的绑定也要跟着变，脚本换完就 stamp 一次——不盖的话 `场景记忆.mjs check` 会立刻报「卡指纹过期」，看着像记忆坏了
- **压力到阈值会自动换**：默认「上下文用掉 88% + 至少 20 轮 + 空闲 10 分钟 + 同面板 30 分钟冷却」，每 5 分钟检查一次、一次只换一个；要关掉就把 `外壳\data\自动换会话.json` 的 `enabled` 改成 `false`
- 想确认没写坏：`node 工具\场景记忆.mjs check --场景 <名字>`；换会话过程看 `外壳\data\换会话日志.jsonl`（旧的 `换会话日志.txt` 已于 2026-11-13 删除，只保留 jsonl）
- 看所有场景状态：`node 工具\场景记忆.mjs list`
- 细节与排障：`doc\换会话自动化.md`

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 双击 启动.vbs 提示没装依赖 | 先 `cd 外壳 && npm install` |
| 启动后停在引擎页 | 点顶栏的场景标签；或等 10 秒它会自动进「命令」 |
| 面板空白 | 顶栏 ⟳ 刷新；再不行看 `外壳\server.log` |
| 端口被占 | 改 `启动.vbs` 里 `DSH_PORT`（默认 3083）或直接设同名环境变量；⛔ 不要改脚本里的数字 |
| 想换引擎位置 | 改 `引擎\` junction 指向你的 DSH 引擎目录 |
| 设置页没有启动动画 | 正常：公开版 2026-11-10 起已移除启动动画插件，不带任何插件 |
