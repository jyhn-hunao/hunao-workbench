# 特效 / 合成（创意工坊 · 岗位技能）

0. **先读**：角色卡 `12-源码照搬\创意工坊\团队\特效合成.md` → `_look_v*.blend` + 工单特效需求。
1. **判断必要性**：无特效需求的资产 ⇒ 回执写"无需特效"，不空跑。
2. **在副本上做**：复制 `_fx_v1.blend` 再改，⛔ 不动 `_look_*` 主文件。
3. **特效**：毛发（粒子/几何毛发）、粒子、体积雾、发光；参数写进脚本注释。
4. **通道**：需要合成时出 AO / Depth / Alpha / ObjectID（多图层 EXR）。
5. **合成**：Compositor 做景深/辉光/色彩校正 → `资产\<资产>\render\comp\<资产>_<帧或静帧>.png/exr`。
6. **边界**：⛔ 不改网格/UV/贴图；⛔ 不替代灯光定曝光构图；⛔ 不交付缺通道的合成；⛔ 无工单不自行加特效。
7. **收工**：回执给特效类型、通道清单、帧范围、合成节点要点、渲染耗时。
## 标准（不在本技能里重复）

量化阈值与回执格式以 `12-源码照搬\创意工坊\流水线.md` 第六节（交付标准）、第七节（回执模板）为准；工单里的数值优先于流水线默认值。本技能只写工序与边界，冲突以流水线为准。
