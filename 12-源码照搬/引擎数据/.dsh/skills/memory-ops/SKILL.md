# 记忆维护

一句话：记忆是**文件**，可靠性靠**工具**不靠自觉——所以下面每一步都有命令，跑完看退出码，别凭"我记得写了"。

## 0. 先认三层（串味必然漂移）

| 层 | 位置 | 放什么 | 体量 |
| --- | --- | --- | --- |
| 注入层 | `引擎数据\.dsh\AGENTS.md` | 铁律 + 命令表，每轮注入 | 越短越好 |
| 私有层 | `场景记忆\<场景>\场景私有记忆.md` + 同目录 `决策\`、`坑\`、`通知\` | §〇 交接（≤4 KB）、§五 **只放下标**；正文一条一个文件 | 主文件 12 KB 该拆 / 25 KB 红；单篇 ≤2 KB |
| 项目层 | 薄卡 `场景记忆\程序开发\项目记忆\<项目>.md` + `<项目根>\memory\` | 卡只放指针，正文按需召回 | 单篇 ≤2 KB |

同一句话只准住一层。⛔ 不要把规范正文复制进这三处（三份必漂移）。

## 1. 开场：读交接，不整读

```powershell
node 12-源码照搬\工具\场景记忆.mjs 读 --场景 <场景目录> --节 §〇   # 2–4 KB
```

⛔ 别整读 25 KB 的 `场景私有记忆.md`；项目记忆也别整贴 `memory\`。

## 2. 干活中：按需召回

```powershell
node 12-源码照搬\工具\记忆.mjs recall --project "<项目根>" "<关键词>"
```

top 5–8、≤2 KB、默认滤掉低分（`--min` 调阈值，`--no-log` 关流水）。空命中就直接 grep 代码，不猜、不阻塞。

## 3. 干完：写回一步到位

```powershell
node 12-源码照搬\工具\记忆.mjs 写 --project "<项目根>" --类 pitfalls --标题 "xxx" `
  --正文 <草稿.md> --证据 "<文件>::<文件里的一句话>" --标签 a,b
```

- 工具自动补 frontmatter、落 `memory\<类目>\<日期>-<标题>.md`、重跑 `index`、再跑 `check`；**check 不过退出 1** → 按条目修完才算完成，别说"已记录"。
- **决策/坑（`decisions` / `pitfalls`）必须带 `--证据`**；确实没有就写 `--无证据 "原因"`（进 frontmatter `no_evidence`，体检按已交代算）。近 30 天缺证据 = 体检 ✗，存量缺证据只 ⚠。
- `--证据` 是给三个月后的自己：`文件::片段`，`体检` 逐条复核，文件改了就报「证据失效」（这是发现记忆过时的唯一自动手段）。
- 只写结论（现象 / 判据 / 绕法 / 结论），超过 2 KB 工具会提示"写的是过程不是结论"。

**场景记忆写一条**（§五 只放下标，正文不许再往主文件里加）：

```powershell
node 12-源码照搬\工具\场景记忆.mjs 写 --场景 <场景> --类 决策|坑|通知 --标题 "一句话结论" `
  --要点 "甲|乙|丙"            # 或 --正文 <草稿.md>
  --证据 "12-源码照搬/工具/场景记忆.mjs::function cmdSplit"
```

同名条目会被拒（退出 1）；写完同轮 `check`，单篇 >2 KB 或主文件 >25 KB 直接判红。

## 4. 收尾 / 换会话：过闸门

```powershell
node 12-源码照搬\工具\场景记忆.mjs 交接 --场景 <场景>
node 12-源码照搬\工具\记忆.mjs 体检 --project "<项目根>"    # exit 0 才算收工
```

体检八项：结构 / 词表 / 证据 / 召回活性 / 备份 / 体量 / 新鲜度 / 场景层；✗ 必须修，⚠ 是提醒。

## 5. 坏了怎么办

- **记忆和代码不一致**：改代码那轮顺手改记忆，别攒；体检报「证据失效」→ 更新或删那条。
- **check 不过**（指纹过期 / 重复副本 / 索引过期）：按提示跑 `stamp` / `init` / `index`；⛔ 别手改 `_索引.json`、身份卡、画像。
- **场景记忆长胖了**（`check` 报主文件 >25 KB，或 §五 里还是成堆正文）：先 `拆 --场景 <场景> --dry` 看计划与对账，再去掉 `--dry` 真拆（原文整份进 `归档\`，§五 换下标）；条目过老用 `整理 --场景 <场景> [--days 180]`。拆完核对"原文条目数 vs 拆出文件数"，别信"应该没丢"。
- **正文没版本**：`memory\` 不入库（公开模板不推本机路径）→ 定期 `记忆.mjs 备份`（默认留 10 份、自动进 `.gitignore`）。
- 详细口径以 `12-源码照搬\说明\记忆约定.md` 为准；本技能只做导航，不复制正文。
