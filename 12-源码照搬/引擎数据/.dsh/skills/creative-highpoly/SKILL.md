# 高模雕刻（创意工坊 · 岗位技能）

0. **先读**：角色卡 `12-源码照搬\创意工坊\团队\高模雕刻.md` → `art.md` 与 `资产\<资产>\ref\*`。
1. **认环境**：`node 12-源码照搬\工具\Blender.mjs probe`。
2. **摆大形**：按三视图对齐比例与体块，别一上来抠细节；尺寸对齐工单（米制）。
3. **雕细节**：Sculpt / 硬表面；位移与毛发只做雏形并在回执注明"仅为雏形"。
4. **另存** `资产\<资产>\<资产>_hi_v1.blend`（面数不设上限，回执写实际三角数）。
5. **交审**：截图交美术指导 + 导演对造型，通过才进低模。
6. **边界**：⛔ 不做拓扑/UV/贴图/材质灯光；⛔ 不覆盖任何 `_lo_/_uv_/_look_`；⛔ 不擅自改造型（不符原画先回美术指导）；⛔ 不写盘根/桌面。
7. **收工**：回执给面数、包围盒、修改器/笔刷、已知偏差。
## 2026-11-13 增补（流水线 §6.4）
- **基座优先**：先找 `工作区\创意工坊\_基座\` 的 base mesh，做**改造**（对齐比例、换头/换手、加装备、保持四边面环线），⛔ 不从零捏人形；
- 没有基座才 blockout 起，且 brief 必须标「无基座，造型品质受限」；
- 回执写：基座文件路径 + 许可、改动清单、面数、包围盒误差（≤2%）。
