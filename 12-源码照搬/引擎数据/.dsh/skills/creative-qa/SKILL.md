# 技美 / 质检（创意工坊 · 岗位技能）

0. **先读**：角色卡 `12-源码照搬\创意工坊\团队\技术美术质检.md` → 工单验收清单 + 当前版本产物。
1. **低模预检**（`_lo_v*.blend`）：命名前缀、重名对象、负缩放、孤立顶点、非流形边、N 边形、三角面预算、原点与单位。不过退低模岗。
2. **UV/贴图预检**（`_uv_v*.blend` + `资产\<资产>\tex\`）：UV 在 0–1、是否重叠、texel density；贴图 ≤2K、**丢贴图**（filepath 不存在 / `has_data=False`）、是否打包/相对路径。不过退 UV 岗。
3. **终检 + 导出**：全项复核 → `资产\<资产>\export\<资产>.glb` → **重新导入回读**比对对象数/三角数/材质数/贴图数。
4. **报告**：`资产\<资产>\render\qc\<资产>_qc.md`——通过/不通过 + 实测值 + 问题按岗位归类。
5. **边界**：⛔ 有问题不放行、不写"基本没问题"；⛔ 不代修资产；⛔ 不跳过回读；⛔ 不看图不签通过；⛔ 不覆盖他人文件。
6. **收工**：回执给通过与否、实测数字、GLB 大小、回读结果。
## 2026-11-13 增补（流水线 §6.6）
- **QC 以脚本输出为准**：`node 工具\Blender.mjs run --script 工作区\创意工坊\_脚本\模板-质检.py --blend <资产>.blend`，看 `QC_PASS` / `FAIL` 行；
- 必查：非流形、孤立点、负缩放、N边形、**每顶点权重 ≤4**、UV 在 0–1、贴图 ≤2K 且不丢、骨骼数与 DEF 骨数；
- 交付前再跑 `node 工具\资产.mjs check --name "<资产名>"`：**GLB 无 skin = 不通过**（可操作资产的核心红线）。

## 标准（不在本技能里重复）

量化阈值与回执格式以 `12-源码照搬\创意工坊\流水线.md` 第六节（交付标准）、第七节（回执模板）为准；工单里的数值优先于流水线默认值。本技能只写工序与边界，冲突以流水线为准。
