# 程序开发

1. **先认现场（顺序不能反）**：① `外壳\\scenarios\\code-dev-context.md`（定位卡）→ ② `场景记忆\\程序开发\\场景私有记忆.md` 的 §〇 交接 → ③ **`场景记忆\\程序开发\\项目记忆\\<当前项目>.md` 的「领域与术语 / 数据来源与业务规则 / 接口与契约」** → ④ 该项目 `AGENTS.md`。
   当前项目 = 会话 cwd 对应的仓库名（§〇 第 2 小节的当前项目表里也有）；项目记忆没有就先按 `project-onboarding` 生成，不要先写代码。
2. **认规范**：规范正文在 `~/.dsh/standards/specs/个人编码与AI协作规范.md`；铁律 = 先思路后代码、代码内 `// 1. xxx` 中文编号伪代码、数据来源可证明、不静默兜底、只改相关、交付八项。
3. **干**：M/L 级先给方案等确认；S 级直接改。只改本次相关段落，不顺手重构/格式化。
4. **验**：按项目 `AGENTS.md` 的命令实跑（编译/测试/自检），把结果贴出来；`没跑` 不等于 `通过`。
5. **提交**：按该项目 `doc\\提交准则.md`——一个可独立审查的逻辑单元、`type(scope): 中文摘要`、阈值内、按远程策略推送。
6. **写回（分两处，别串）**：业务知识（术语 / 数据来源 / 接口契约 / 领域规则）→ `项目记忆\\<项目>.md`；跨项目规矩与工具坑 → 场景 §五；本轮进度 → 场景 §〇。项目规范变了同步更新 `doc\\迁移报告.md` 的基线。
7. **接新项目**：不要手搓流程，走技能 `project-onboarding`。
