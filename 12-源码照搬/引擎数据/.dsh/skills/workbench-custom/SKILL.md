# 工作台定制

1. 先读 `外壳\\scenarios\\workbench-custom-context.md`（定位卡）与 `引擎数据\\.dsh\\场景记忆\\工作台定制\\场景私有记忆.md` 的 §〇 接手。
2. 动手前先定位到「文件:行」（`grep` 出证据，不猜）；只改本次相关段落，主流程写 `// 1. xxx` 中文编号注释。
3. 改完必须验：`node 12-源码照搬\\外壳\\scripts\\自检.mjs` + `node 12-源码照搬\\外壳\\scripts\\sessions.mjs --check`；面板/场景改动切一次场景看实际效果，别只看代码。
4. 提交按 `doc\\提交准则.md`（`type(scope): 中文摘要`、≤8 文件 / ≤300 行），只推 gitee 的 `hunao-workbench`，绝不推 `upstream`。
5. 干完把结论写回 §〇 / §五；要别的场景配合：`node 12-源码照搬\\工具\\发消息.mjs --to <场景目录> "内容"`。
