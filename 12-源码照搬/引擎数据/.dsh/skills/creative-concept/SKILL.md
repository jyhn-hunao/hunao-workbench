# 原画 / 概念（创意工坊 · 岗位技能）

0. **先读**：角色卡 `12-源码照搬\创意工坊\团队\原画概念.md` → `资产\<资产>\ref\art.md`。
1. **拆图单**：三视图（正/侧/背）必需 + 气氛图 1 张 + 关键材质局部 1–2 张。
2. **出图：默认 Seedream（`工具\生图.mjs`，火山方舟）**：
   - 一条命令：`node 工具\生图.mjs gen --prompt "<提示词>" --out "资产\<资产>\ref\concept_<资产>_front.png"`；默认模型 `doubao-seedream-4-5-251128`、2K、无 AI 水印，返回 b64 直接落盘（按魔数判 png/jpg 后缀）。
   - 有用户给的参考图就加 `--ref "资产\<资产>\ref\<资产>-ref.png"`（也接受 http URL，最多 14 张）；要一次出多版加 `--n 2`。
   - 提示词必须写：视角（正交三视图 / 45° 透视）、比例、配色（照 art 的十六进制）、材质关键词、纯色背景（看轮廓）、负面词。
   - `probe` 报"缺 key"就是真缺（环境变量 `ARK_API_KEY` 或 `机器配置.json` 的 `arkApiKey`）⇒ 直说并交导演转用户，⛔ 不许假装出了图、⛔ 不拿渲染图充概念图。
   - 兜底：三视图可用 Blender 正交灰模渲染（`工具\Blender.mjs run --script …`，EEVEE 960×540 实测 27 s），只当造型参考。
3. **写 `说明.md`**：关键尺寸（米）、造型特征 3–5 条、材质分区、可简化细节。
4. **交美术指导审**；返工按审图清单重出图。
5. **边界**：⛔ 不进 Blender、不改工程、不导模型；⛔ 不用生图冒充渲染图/工程截图；⛔ 图里不出现品牌 logo、真人肖像、受版权保护的具体角色。
6. **收工**：回执给图清单（文件名 × 用途）、定稿版本、被否掉的点。
## 标准（不在本技能里重复）

量化阈值与回执格式以 `12-源码照搬\创意工坊\流水线.md` 第六节（交付标准）、第七节（回执模板）为准；工单里的数值优先于流水线默认值。本技能只写工序与边界，冲突以流水线为准。
