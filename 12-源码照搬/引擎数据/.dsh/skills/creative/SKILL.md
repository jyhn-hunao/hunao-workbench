# 创意工坊

0. **先认现场（顺序不能反）**：① 定位卡 `外壳\scenarios\creative-context.md` → ② 场景 §〇：`node 工具\场景记忆.mjs 读 --场景 创意工坊 --节 §〇`（⛔ 不整读主文件）→ ③ `node 工具\Blender.mjs probe`（装没装、跑没跑、桥接通不通、工程根在哪）。
   - `probe` 说没装 ⇒ 直说「本机没找到 Blender」，把补法给用户（`set-exe --path "<blender.exe>"` 或设 `DSH_BLENDER_EXE`）；⛔ 不猜路径、不擅自下载安装包。
   - `probe` 说桥接不通但 Blender 开着 ⇒ 让用户在工作台「Blender」面板点「⧉ 重新内置」或关掉重开（启动时才带桥接脚本）。

1. **两条路，先分清再用**：
   - **实时（exec）**：用户正开着 Blender，要「在当前这个场景里」加东西 / 改材质 / 读数 → `node 工具\Blender.mjs exec --file <脚本.py>`。只做增量，⛔ 不对用户正在编辑的工程做全量重建、⛔ 不删他建的对象。
   - **后台（run）**：无人值守出模型 / 批处理 / 大批量渲染 → `node 工具\Blender.mjs run --script <脚本.py> [--blend <工程.blend>]`。会新开一个 `--background` 进程，不打扰界面。
   - 要打开某个工程给用户看：`node 工具\Blender.mjs open --blend <工程.blend>`（带桥接，打开后即可 exec）。

2. **工程根与产物**：`12-源码照搬\工作区\创意工坊\`（`probe` 会打印实际路径），子目录固定：
   - `资产\<资产>\`（.blend）· `资产\<资产>\render\`（渲染图 / 序列）· `资产\<资产>\export\`（.glb / .fbx / .obj）· `_脚本\`（AI 生成的 bpy 脚本，文件名带日期）
   - ⛔ 不写盘根、桌面、C 盘临时目录；⛔ 不在工程根顶层丢散文件；同名 `.blend` 覆盖前先问用户。

3. **写 bpy 脚本的口径**（run / exec 共用）：
   - 入口写清 `# 1. 清场 / 2. 建模 / 3. 材质 / 4. 灯光相机 / 5. 保存 / 6. 渲染或导出` 中文编号注释；
   - 保存要显式 `bpy.ops.wm.save_as_mainfile(filepath=...)`，渲染要显式设 `resolution_x/y`、`engine`、`samples`；
   - 导出 GLB：`bpy.ops.export_scene.gltf(filepath=..., export_format='GLB')`；
   - 脚本失败就让它失败（`run` 带 `--python-exit-code 1`），⛔ 不 try/except 全吞。

4. **验**：跑完必须回读证据——`run` 看退出码 + 输出文件是否存在且大小合理；`exec` 看回包 `ok` 与返回值；渲染完把输出路径、分辨率、引擎、采样数报给用户。没出图就报错，⛔ 不写「已完成」。

5. **只碰 Blender 与本场景产物**：改工作台代码 / 改面板 / 换会话 / 装依赖 ⇒ 派给「程序开发」（`node 工具\派发.mjs --to "程序开发·工作区" "..."`），⛔ 不在这个场景里动壳。

6. **你是制片 / 导演，不是全能工**（2026-11-13 分为十岗后）：
   - 十岗 = 十条会话：`创意工坊`（你）· `创意工坊·美术指导` · `创意工坊·原画概念` · `创意工坊·高模雕刻` · `创意工坊·低模拓扑` · `创意工坊·UV贴图` · `创意工坊·材质灯光` · `创意工坊·绑定动画` · `创意工坊·特效合成` · `创意工坊·技美质检`；
   - 你只做：写 `工单\G-*.md`（brief + 验收清单）、排期、派工、卡门（用户确认 brief / art 风格 / 原画审 / 高模造型 / test 图 / QC）、汇总交付；⛔ 不亲手改资产；
   - 派工：`node 工具\派发.mjs --to "创意工坊·原画概念" --file "<工单.md>" --timeout 1800`；回执由对方执行派发消息里附的 `回执.mjs` 命令；
   - 串行链：同一资产 高模 → 低模 → UV → 材质 → （按需绑定/特效）→ 质检；⛔ 不许并行改同一个 `.blend`；
   - 并发：Blender 实时通道同一时刻只许一个岗位 `exec`（工单写"占用时段"）；`run --background` 可并行但同一 `.blend` 不许双写；
   - 全套流程与验收标准见 `12-源码照搬\创意工坊\流水线.md`，各岗细节见 `12-源码照搬\创意工坊\团队\*.md`；本技能不重复抄流程，冲突以流水线文件为准。

7. **收工**：结论写回 `node 工具\场景记忆.mjs 写 --场景 创意工坊 --类 决策|坑 --标题 "…" --要点 "…" --证据 "<路径>::<片段>"`；一条命令收工 `node 工具\场景记忆.mjs 收工 --场景 创意工坊`（exit 0 才算完）。
