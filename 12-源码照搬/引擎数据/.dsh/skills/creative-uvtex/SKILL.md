# UV / 贴图（创意工坊 · 岗位技能）

0. **先读**：角色卡 `12-源码照搬\创意工坊\团队\UV贴图.md` → `_lo_v*.blend` + art 配色 + 原画材质稿。
1. **UV 展开**：接缝藏在不显眼处；texel density 均匀；UV 在 0–1；无重叠（镜像 UV 要标注）。
2. **烘焙**（有高模时）：Cycles bake 法线/AO/曲率，从 `_hi_v*.blend` 烘到低模 UV；margin ≥ 8 px，参数写进脚本注释。
3. **贴图**：基础色/粗糙度/金属度/法线/AO；单张 ≤ 2K；命名 `TEX_<资产>_<通道>`；放 `工作区\创意工坊\资产\<资产>\tex\<资产>\`。
4. **接槽**：贴图接进材质槽，但⛔ 不调 Shader 参数（归材质灯光）。
5. **丢贴图自检**：`image.filepath` 存在、`has_data=True`、相对路径或已打包。
6. **另存 `_uv_v1.blend`**，交技美预检（UV 重叠/丢贴图/尺寸）。
7. **边界**：⛔ 不改几何/布线/命名；⛔ 不布光、不写 Shader 参数；⛔ 贴图不超 2K、不写绝对路径。
8. **收工**：回执给 UV 岛数、贴图清单（通道 × 分辨率 × 大小）、镜像/重叠、烘焙耗时。
## 2026-11-13 增补（流水线 §6.6 第 1 条）
- **展开 → 烘焙 → 回写**：`bpy.ops.uv.smart_project` 打底（或按部位手工分区）→ 烘焙到 `资产\<资产>\tex\` → 材质贴图回写 → 丢贴图 = 0；
- 验收：UV 全在 0–1、重叠面积 0（镜像 UV 要标注）、texel 偏差 ≤20%、单张 ≤2K、烘焙 margin ≥8 px。
