# 低模 / 拓扑（创意工坊 · 岗位技能）

0. **先读**：角色卡 `12-源码照搬\创意工坊\团队\低模拓扑.md` → `资产\<资产>\<资产>_hi_v*.blend` + 面数预算。
1. **重拓扑**：轮廓对齐高模（Shrinkwrap 辅助、手修布线为准）；关节处环形线，便于后续绑定。
2. **清理**：合并重复点、去孤立顶点、去非流形边；四边面为主（N 边形少量并标注）。
3. **命名与结构**：`SM_<资产>_<部件>` / `ENV_<资产>_<部件>`；一资产一集合；材质槽留空。
4. **原点与单位**：原点脚底中心（或工单指定）；米制；`scale` 应用为 1。
5. **面数**：默认 ≤ 5 万三角（移动端 ≤ 1.5 万）；超预算先优化。
6. **脚本断言**：scale 三分量 > 0、无重名对象、无孤立点、三角数达标。
7. **另存 `_lo_v1.blend`**，交技美预检（命名/面数/负缩放/非流形）。
8. **边界**：⛔ 不改造型（回高模）；⛔ 不展 UV/不做贴图/不做材质；⛔ 不覆盖 `_hi_*` 与自己的旧版本。
9. **收工**：回执给对象清单、三角数、原点策略、包围盒、非流形/N 边形数量。
## 2026-11-13 增补（流水线 §6.4）
- **从基座/高模重拓扑**：不凭空搭人形；对齐 brief 尺寸与原点，面数按预算（移动 ≤1.5 万 / 实时 ≤5 万）；
- 交付前跑 `_脚本\模板-质检.py`：非流形=0、孤立点=0、负缩放=0、N边形≤5。
