# 接入新项目（复用流程）

> 目的：让"接入一个项目"变成一条可重放的流程，而不是每次现想——五次里漏一次（尤其忘了回写 sessionId），
> 表现是"面板看着正常但钉不到会话"，而且不报错。

## 〇、先问清三件事（缺一件就停下来问）

| 要确认 | 为什么 |
| --- | --- |
| 项目根目录（绝对路径） | 它同时是 DSH 工作区、会话 cwd、git 仓库根 |
| 显示名 | 会话标题、面板 pinTarget、项目记忆文件名都用它；改名要动四处 |
| 技术栈 / 有无既有 `AGENTS.md` | 决定第 4 步用哪几份附录、是新建还是合并 |

## 一、接进工作台（脚本一次做完 1–3 步）

```powershell
cd <工作台>\12-源码照搬
$env:DSH_GUI_BASE = 'http://127.0.0.1:3083'      # 端口以 启动.vbs 的 DSH_PORT 为准
node 外壳\scripts\接入项目.mjs --root "<项目根>" --name "<显示名>"
```

脚本做四件事，任一失败会直接报错退出（不会留半套）：
1. 查 `引擎数据\.dsh\storages\workspace.json`，该项目没有工作区就调 `workspace/create` 建一个；
2. `session/create`（挂该工作区）→ `session/rename` 成显示名；
3. 把 `sessionId` / `sessionTitle` / `pinTarget` 写进 `外壳\scenarios\code-dev.json` 的 AI 面板；
4. 建 `项目记忆\<显示名>.md` 骨架（状态区 + 业务区），并把 `_共享记忆\项目.json` 里该项目的 `memory` 指过去。

参数：`--no-bind` 只建会话不写面板；`--dry` 只检查；`--memory-only` 只补项目记忆与登记（给已接入的项目补业务记忆）。

**为什么必须一个项目一条会话**：规范文件按会话 cwd 生效——cwd 落在项目根，那个仓的 `AGENTS.md` 才会自动进上下文；
一条会话跑多个项目会把几套项目规则混在一起。

## 二、生成项目规范（第 4 步，不能省）

按 `~/.dsh/standards` 的 README「迁移到具体项目：AI 执行顺序」0–8 步做，产出三份：

| 文件 | 内容 | 硬要求 |
| --- | --- | --- |
| `<项目>\AGENTS.md` | 定位、目录归属、命令、技术栈约定、编码与交付要求、提交与远程、禁止项、风险 | 只写项目值与差异，不复制规范正文；每个值带 `文件:行` 证据 |
| `<项目>\doc\提交准则.md` | type / scope 词表、粒度阈值、提交前 gate、远程策略、拆分示例 | 阈值只能比通用更严 |
| `<项目>\doc\迁移报告.md` | 事实清单、迁移矩阵（已落地 / 不适用 / 待确认）、待确认清单、验证记录、**规范基线 commit** | 三态齐全，已落地行必须有证据 |

自检：

```powershell
powershell -File ~/.dsh/standards/install/verify.ps1 -Segment project,drift -Project "<项目根>"
```

要求 `FAIL 0`；`UNVERIFIABLE` 要人工确认并在报告里写结论，不能当通过。

## 三、填项目记忆（第 5 步，脚本已建骨架）

**业务记忆按项目隔离**：一个项目一份，别的项目读不到。

1. 打开 `引擎数据\.dsh\场景记忆\程序开发\项目记忆\<显示名>.md`，填三节：
   - **领域与术语**：业务域、专有名词与口径、边界（什么事不属于它）；
   - **数据来源与业务规则**：数据从哪来（表 / 接口 / 文件）、谁维护、哪些字段脏、规则与例外；
   - **接口与契约**：对外接口、字段含义、跨端约定、版本。
2. `_共享记忆\项目.json` 里该项目的 `memory` 已由脚本指向这个文件；神经元面板据此显示项目。
3. ⛔ 业务知识**不要**写进 `程序开发\场景私有记忆.md`——那里只放跨项目规矩（`场景记忆.mjs check` 会在出现项目名时告警）。
4. 场景 §〇：把"接了哪个项目、当前卡在哪、下一步"写进 `程序开发\场景私有记忆.md`。

## 四、验收（四项全过才算接完）

```powershell
node 外壳\scripts\sessions.mjs --check        # 面板 sessionId 命中、标题一致
node 外壳\scripts\自检.mjs                     # 场景 json 数量与结构
node 工具\场景记忆.mjs check --场景 程序开发     # 记忆骨架
```

- 顶栏 ⟳ 切到「程序开发」，面板里应显示该项目的会话；
- 在会话里问一句"我在哪个项目、按哪份规范"，能答出 cwd + 该项目 `AGENTS.md` 的关键条目。

## 五、坑（每条都真踩过）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 侧栏里会话掉进「未分组」 | 工作区没登记，或登记的路径与 cwd 不一致 | 重跑脚本；路径必须逐字一致（只差盘符大小写也可能不认） |
| 面板开着但"钉不到会话" | `sessionId` 没回写，或标题与界面显示不一致 | 跑 `sessions.mjs --check` 看是缺 id 还是标题不符 |
| 脚本报"换不到 cookie" | 引擎没跑，或 `server.log` 里没有本端口的 token | 先启动 `启动.vbs`；端口必须与 `DSH_GUI_BASE` 一致 |
| 改完面板没变化 | 场景在切场景时才重建 | 顶栏 ⟳ 或切走再切回 |
| 新项目没规则 | 只接了会话，没做第 4 步 | 补 `AGENTS.md` + `doc\迁移报告.md`，再开新一轮干活 |
