# 工作台内置规范（自包含）

> 本目录是 `luanyujia-workbench` 自己的规范副本。工作台把规范当作项目配置的一部分：随仓库分发、随仓库评审、随仓库回滚。
> 不读取、不依赖桌面端宿主目录；桌面端那份规范只服务桌面端。

## 目录

- `specs/`：通用正文 + 4 份技术栈附录 + 3 份通用协作附录（提交准则、文档记忆体系、界面与交互设计）+ 2 份用户层（`个人偏好.md`、`用户画像.md`）。
- `rules/iron-rules.txt`：13 条常驻铁律，供 `12-源码照搬/引擎数据/.dsh/AGENTS.md` 每轮引用。

## 来源与基线

- 上游：`https://gitee.com/ydcy_studio/ai-compilation-specifications`
- 复制基线：`881e4da` + 2026-11-17 工作区增补（§14 与 `附录-界面与交互设计.md`）。
- 用户层 `个人偏好.md` / `用户画像.md` 也随工作台内置；它们含个人资料（身份、工作背景、协作习惯），**若仓库要公开或推送到公开远端，先脱敏**，或改用私有仓。

## 更新方式

1. 从上游复制 `specs` 正文到本目录。
2. 保留 `specs/个人编码与AI协作规范.md` 中「工作台自带」的差异段（安装位置、0.3、0.4、个人偏好层说明）。
3. 同步 `rules/iron-rules.txt`。
4. 跑 `node 12-源码照搬\外壳\scripts\检查内置规范.mjs`。

## 为什么不在项目根再复制一份

规范正文只保留这一份工作台副本；项目 `AGENTS.md`、场景定位卡、场景记忆都只引用它，不复制正文。复制多份必然漂移。
