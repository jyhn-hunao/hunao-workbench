# 面板 agent 工具进程没有 DSH_TOKEN

## 要点
- token 只在壳进程内存，scriptEnv 只注入壳 spawn 的子进程；引擎 spawn 的 agent 工具进程 env 没有 DSH_TOKEN，server.log 已脱敏成 token=***
- 症状：回执.mjs / 派发.mjs 报「换不到 cookie」，而 3083 实际在跑
- 绕法（已验证）：读壳主进程 env 块（NtQueryInformationProcess+ReadProcessMemory）取 DSH_TOKEN，置环境变量 DSH_TOKEN 再跑回执，exit 0 投递成功
- 找壳主进程：electron.exe 里 ParentProcessId 不是 electron 的那个；壳重启后 PID 会变（2026-11-24 从 8720 换成 36232），每次重查
