# 创意工坊细分十岗：原画与美术、UV与材质、高模与低模拆开

## 要点
- 十岗 = 十个 AI 面板 = 十条独立会话；面板 cw-ai/art/concept/hi/lo/uv/look/rig/fx/qa，会话标题各带「创意工坊·」前缀
- 新增岗位：美术指导（定风格并审原画/高模）、原画概念（用生图工具出三视图/气氛图，落 概念\）、UV贴图（UV+烘焙，贴图 ≤2K）、高模雕刻、低模拓扑、绑定动画（按需）、特效合成
- 门序：用户确认 brief → art 风格 → 美术指导审原画 → 高模造型 → 技美预检（低模：命名/面数/非流形；UV：重叠/丢贴图/尺寸）→ 导演审 test 图 → QC 回读通过
- 串行链同一资产：高模 → 低模 → UV → 材质 →（按需绑定/特效）→ 质检；版本 _hi/_lo/_uv/_look 不覆盖
- 原「建模」会话已 rename 成「创意工坊·高模雕刻」；旧 creative-modeler 技能删除，改为 creative-artdirector/concept/highpoly/lowpoly/uvtex/rig/fx 七个岗位技能
