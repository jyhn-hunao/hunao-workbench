# Blender 便携版装在 工作区_工具，不进系统目录

## 要点
- 版本 4.5.16 LTS 便携版（portable 模式），落 工作区\创意工坊\_工具\Blender\blender.exe，机器配置 blenderExe 已登记，无需系统安装
- 候选来源：阿里云镜像 ~290KB/s 太慢，改清华镜像 TUNA（~776KB/s），sha256 校验一致
- 实测：run 后台脚本 OK（4.5.16 / Python 3.11.15）、open 挂桥接后 9876 通、exec 表达式返回 1+1=2、语句模式改名后读回一致、quit 后 probe 显示未运行
- 中文 --python 脚本路径在 4.5.16 可用（不再需要为 run 复制到临时 ASCII 路径）；桥接脚本仍按旧口径复制到 %TEMP%
- 安装包与冒烟工程已删，_工具 占 889 MB，工作区被 .gitignore 挡着不进公开仓
