# 人格层 · 场景索引

> 「提到哪个场景，就去哪儿取上下文」。这里只写**去哪读**，不复制别人的正文。
> 读法：`node 12-源码照搬\工具\场景记忆.mjs 读 --场景 <场景> --节 §〇`（只取交接，别整读）。
> 规矩：业务场景的记忆**只读不写**；要改由那个场景自己的会话改。

| 用户可能这么说 | 场景（记忆目录） | 该找的会话（派发用标题） | 去读什么 |
|---|---|---|---|
| “B站那个视频 / 那条弹幕 / up 主” | `B站` | `B站` | §〇 交接 + `决策\`（选题、脚本、发布口径） |
| “项目里那个 bug / 那个需求 / 代码” | `程序开发` | 工作区：`程序开发·工作区`；单项目：`mlw` 等 | §〇 交接 + `决策\` + `坑\`；项目细节用 `工具\记忆.mjs recall --project "<项目根>"` |
| “记忆怎么管 / 体检 / 交接 / 归档” | `命令` | `命令` | §〇 + 记忆维护的决策（本工作台记忆口径在这里） |
| “磁盘 / 电脑卡 / 清理” | `本地电脑` | `本地电脑` | §〇 + `坑\`（哪些目录不敢动） |
| “复盘 / 这周怎么样 / 我做得如何” | `自我复盘` | `自我复盘` | §〇 + `决策\` |
| “QQ / 飞书 / 通道 / 她怎么回消息” | 通道参数在 `社交`；对话本体在**本目录** | 无 AI 会话（`so-msg` 只是面板） | 通道事实读 `场景记忆\社交\场景私有记忆.md` §一；聊过什么看本目录 `对话\` |

## 派发与回执

- 派活：`node 12-源码照搬\工具\派发.mjs --to "<上面的会话标题>" "<任务>"`（会等回执）
- 收尾：`node 12-源码照搬\工具\回执.mjs --ticket <单号> --summary "<结论>"`
- 台账：`12-源码照搬\引擎数据\.dsh\派发\回执日志.md` + 同目录单子
- ⛔ 项目名只认 `场景记忆\_共享记忆\项目.json`；认不出就列候选问用户，不按目录名猜
