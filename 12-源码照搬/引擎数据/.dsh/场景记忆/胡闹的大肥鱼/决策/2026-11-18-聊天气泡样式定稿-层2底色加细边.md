# 聊天气泡样式定稿-层2底色加细边

## 要点
- 最终参数：对话流 gap 12px；助手气泡 max-width 88%、margin 0 0 8px、padding 12px 16px、底色 --dsw-alias-bg-layer-2、描边 --dsw-alias-border-l2、圆角 --dsw-radius-lg（左下角 6px）、相邻气泡 margin-top -2px；用户气泡只统一圆角（右下 6px），背景继续用引擎的 --dsw-specific-bubble；输入条 composer-card 同款圆角 + focus-within 才描边。变量名清单（主 CSS 实测存在）：--dsw-alias-bg-base/layer-1..4、--dsw-alias-border-l1..l4、--dsw-radius-xs/sm/md/lg/panel；主 CSS 里没有 --dsw-radius-xl（只在 chat 包内联串里见过），别拿它当默认。类名带哈希（Sixlwa_ 前缀）会随版本变，用 [class*="bubble"] 这种片段匹配，别写死前缀。⛔ 不手改引擎；升级后看标题行 diag 的「过程 N 已隐藏 ✓/✗」。
