# 派活是单向 `session/prompt`

2026-11-12（协作机制·跨项目）：派活是单向 `session/prompt` —— 目标会话干完，派发方收不到任何东西（用户实报「任务完成了，但没有回执到这里」）。新增三件套：`工具\派发.mjs`（按标题/id 认会话 → 先落派发单 → 投消息并自动附回执命令 → 后台拉起等回执）、`等回执.mjs`（判据：目标 transcript 里正文含**派发单 id** 的 `user/message` → 其后第一个 `turn/end` = 我们那轮 → 取该轮最后一条 assistant 文本投回派发方；不按时间猜，目标会话忙时也不会取错轮）、`回执.mjs`（目标会话主动回执；找不到单且没 `--to` 直接报错，防回执给自己成环），共用 `派发-公共.mjs`。派发单与 `回执日志.md` 落 `引擎数据\.dsh\派发\`（已加 `12-源码照搬\.gitignore`）。验证：4 个脚本 `node --check` 通过；`派发.mjs --dry` 能认到 `session-cd208a77…` 并落单（turnsBefore=6）；`等回执 --once` 无命中不误回执；`回执.mjs --dry` 正文指向正确派发方。**端到端真投递未做**（会往真实会话投消息并触发一轮），留给下次真实派活验证。文档 `说明\跨会话派发与回执.md`。
