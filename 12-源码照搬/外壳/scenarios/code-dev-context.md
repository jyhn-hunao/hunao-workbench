## 四、流程

1. 认项目 / 规范：cwd + `AGENTS.md`；先读规范正文。
2. 召回：`MEMORY_INDEX` → `recall`；空命中直接读代码。
3. 干：M/L 先思路后代码；`// 1. xxx` 编号伪代码。
4. 验 + 写回：按 `AGENTS.md` 实跑；三触发（完成/决策/坑）同轮 `index` + `check`；提交按项目准则。

## 五、铁律

- ⛔ 规范正文不进项目 / 记忆（三份必漂移）。

- ⛔ `memory\` 与项目 `AGENTS.md` 默认不入库，例外需用户说明；无 `AGENTS.md`/薄卡别先写代码。
