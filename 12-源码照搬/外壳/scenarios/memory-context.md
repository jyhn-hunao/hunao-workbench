## 注入台账（`mem-inject`，2026-11-25）

- 解决什么：`引擎数据\.dsh\logs\memory-recall.jsonl` 一行一轮只记 `scene / panel / mode / bytes`，正文刻意不落盘（含人格卡、§〇、项目路径）⇒ 界面上看不出「这块面板到底注入没注入、注入了哪些段」。
- 入口：AI·记忆 面板标题栏最左的常驻按钮 `▤ 注入台账`（`drawerLauncher: mem-chat`），点开右侧滑出 580px 抽屉；不改网格、不缩神经元。
- 看什么：每个会话面板一行（场景 · 面板 · 状态点 · 轮数 / 今日 / 最后时间 / 字数）；状态点 = 绿今天注入过 / 黄只有历史 / 灰有绑定没记录 / 红最近失败或未绑会话。点一行 → 下半屏出**此刻 dry-run** 的分段（人格卡 / 面板交接 / §〇 / 近期 / 相关条目 / 项目记忆 / 收工规则）与全文。
- 数据来源一条链：`工具\记忆注入台账.mjs`（`台账 --json` / `预览 --场景 --面板 --词 --json`）→ `main.js` 的 `mem-inject:get` → `preload` 的 `app.memInject.get` → `renderers['mem-inject']`。⛔ 渲染层不拼注入文本，拼装真源仍是 `插件\记忆回响\index.js` 的 `build`（`preview()` 直接复用，改口径只改一处）。
- 口径差别：抽屉里是「此刻会注入什么」，不是「上一轮实际注入了什么」；历史正文只在会话转录的 `source.kind="memory-recall"` 消息里（`session.v4.jsonl.zstd`，要解压）。
- 只读：不写流水、不落盘；索引过期由插件就地自愈（与真注入同一口径）。命令行同效：`node 12-源码照搬\工具\记忆注入台账.mjs`。
