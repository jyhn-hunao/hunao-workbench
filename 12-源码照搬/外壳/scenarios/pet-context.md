# 胡闹的大肥鱼 · 定位卡

- 场景 id：`pet`（**开机落点**：`first: true` + `customer-start.js` 的 `FIRST='pet'`，2026-11-14 起）
- 一句话：**人格本体的唯一落点**。她是谁、怎么说、记得什么、什么绝不发，全部在这个场景里；别的场景只取用，不复制。通道怎么接、消息怎么收发归「社交」——人格场景不再复制「通道消息」。
- 面板：`外壳\scenarios\pet.json`（`pet-ai`「胡闹的大肥鱼」= 人格会话，占左侧 23 列、整屏满高；`pet-rail`「设置」= 最右一列（38px）竖排按钮（人格 / 表达 / 关系 / 边界 / 档案 / 定时 / 劲儿 / 派发），一项一个按钮，点一下直接开对应弹窗，不占栅格，设置项由 `外壳\场景配置.js` 一处登记；`派发巡检`= 工具条「派发」按钮开的弹窗（`window.openDispatchBoard`），总入口派发台：待批准 / 定时触发 / 超时未回执 / 补投，关掉弹窗即停 60 秒轮询（2026-11-25 删掉常驻的 `pet-dog` 面板）。桌宠参数（主动性 / 能做什么 / 什么要先问你 / 免打扰 / 场景路由 / 最近派发 / 桌面身体）从「设置 → 人格」进，落 `外壳\data\pet\设置.json`（本机，不入库），弹窗带「恢复默认」）
- 记忆根：`引擎数据\.dsh\场景记忆\胡闹的大肥鱼\`
  - `场景私有记忆.md` §〇 = 人格卡（开场注入就是它，≤4 KB）
  - `记忆\` 长期记忆（人物关系 / 偏好 / 承诺），`对话\` 输入侧流水（谁来找她、聊过什么）
  - `_场景索引.md` 别的场景怎么找、找完谁能写
- 跨场景怎么用（写在 `引擎数据\.dsh\AGENTS.md` 的全局口径里）：任何对话开场读 `场景私有记忆.md` 的 §〇；用户提到某业务场景 → 按 `_场景索引.md` 去那个场景的 §〇 读，**只读不写**。
- 通道：社交场景只做管道（所有平台收进一个 `ch-hub` 面板，内部并列 `ch-qq` / `ch-feishu` / `ch-wechat` 三列 + 「全部消息」）。**通道消息统一看「社交 → 全部消息」**，本场景不再放聚合消息面板。**QQ 私聊/群聊默认各自一条独立 DSH 会话**（`QQ会话.js` 建会话并写 `qq-bridge.config.json` 的 `routes.private/group`），回复由人格层生成；只有 `chatMode=per-chat` 的 route 才不跟人格主会话走。换人格会话时 `换会话.mjs` 会跑 `工具\同步桥接路由.mjs`，它只把仍共用主会话的 route 对齐，独立 route 不动，避免把私聊/群聊冲回同一会话。群聊必须在社交 QQ 卡片的「⚙ 接入设置 → 会话路由」里显式加群号，插件才会监听。
- 工具怎么用：参数在 `外壳\data\pet\设置.json`（本机，gitignored；默认值见 `外壳\pet\设置.默认.json`），弹窗可改，⛔ 不要求人去编辑 JSON。**派活不走手拼地址**：`node 12-源码照搬\工具\桌宠.mjs 派 --文本 "<用户原话>"` 自动查路由表、按 `tools.allow/deny` 硬拦、默认以人格会话为派发方、每次自动记 `场景记忆\胡闹的大肥鱼\派发日志.md`。`confirm` 级**不平派**：落进 `外壳\data\pet\待批准.json`，在 `pet-dog` 面板点【批准】才真派出（`--确认` 仍可用于自检，但日常走面板）。`路由` 只查不派，`能主动吗` 给「要不要主动开口」的判据，`记` 转给 `工具\人格记忆.mjs`，`桥接同步` 手动对齐 routes。
- 记忆怎么落：**一律走工具** — `桌宠.mjs 记 --类 记忆|对话|待办 …` 落 `记忆\` / `对话\` / `_待办.md`，自动补索引、跑场景记忆闸门；`人格记忆.mjs 读 --词` 召回、`归档 --天 180` 搬老条目、`体检` 查索引孤儿。开关与「写前确认」在 ⚙ 设置 的「她怎么记事」里。

## 边界（写回复与写记忆都按这三条）

1. 对外一律先自报是 AI，不伪装真人。
2. 钱 / 承诺 / 个人信息，先说清再等人确认；不替用户在第三方平台登录、发言、下单。
3. 各业务场景的 `决策\`、`坑\` 归它们自己维护，人格层只读不改。

## 记忆自主管理（每轮收工前）

- 有新结论就写：`node 12-源码照搬\工具\场景记忆.mjs 写 --场景 <本场景> --类 决策|坑 --标题 "一句话结论" --要点 "a|b" --证据 "<路径>::<片段>"`。只写结论，不写过程、不抄对话、不抄报错原文。
- **拿不准就问**：听来的、推断的、证据不足的、和已有条目很像的 ⇒ 加 `--不确定 "要问用户的那一句"`，进 `_待确认.md`，**不生效**；当轮就问用户，点头后 `确认 --场景 <本场景> --序号 N`，否掉 `--放弃`。
- **词像但不是一回事**：`--不是同一条 "词：区别在哪"` ⇒ 写进 `distinct`，联想层不再用这个词连边。
- 接任务先回想：`node 12-源码照搬\工具\场景记忆.mjs 召回 --场景 <本场景> --词 "<任务关键词>" --条 5`；每轮引擎插件已注入 §〇/近期，别再整读主文件。
