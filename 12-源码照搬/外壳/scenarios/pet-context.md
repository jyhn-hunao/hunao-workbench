# 胡闹的大肥鱼 · 定位卡

- 场景 id：`pet`
- 一句话：**人格本体的唯一落点**。她是谁、怎么说、记得什么，全部在这个场景里；别的场景只取用，不复制。
- 面板：`外壳\scenarios\pet.json`（一格 `pet-ai`「胡闹的大肥鱼」= 人格会话；**设置不常驻**——标题栏「⚙ 设置」点开弹窗，可改主动性 / 能做什么 / 什么要先问你 / 免打扰 / 场景路由（可增删选）/ 最近派发，并带「恢复默认」）
- 记忆根：`引擎数据\.dsh\场景记忆\胡闹的大肥鱼\`
  - `场景私有记忆.md` §〇 = 人格卡（开场注入就是它，≤4 KB）
  - `记忆\` 长期记忆（人物关系 / 偏好 / 承诺），`对话\` 输入侧流水（谁来找她、聊过什么）
  - `_场景索引.md` 别的场景怎么找、找完谁能写
- 跨场景怎么用（写在 `引擎数据\.dsh\AGENTS.md` 的全局口径里）：任何对话开场读 `场景私有记忆.md` 的 §〇；用户提到某业务场景 → 按 `_场景索引.md` 去那个场景的 §〇 读，**只读不写**。
- 通道：社交场景只做管道（每个平台一格卡片 `ch-qq` / `ch-feishu` + 「全部消息」），QQ 的 `routes.private` 直接绑本场景这条会话，回复由人格层生成，与社交场景记忆无关。换会话时 `换会话.mjs` 会自动跑 `工具\同步桥接路由.mjs` 把 routes 指到新会话（不用再手改）。
- 工具怎么用：参数在 `外壳\data\pet\设置.json`（本机，gitignored；默认值见 `外壳\pet\设置.默认.json`），弹窗可改，⛔ 不要求人去编辑 JSON。**派活不走手拼地址**：`node 12-源码照搬\工具\桌宠.mjs 派 --文本 "<用户原话>"` 自动查路由表、按 `tools.allow/deny` 硬拦、`confirm` 级要人加 `--确认`、默认以人格会话为派发方、每次自动记 `场景记忆\胡闹的大肥鱼\派发日志.md`；`路由` 只查不派，`能主动吗` 给「要不要主动开口」的判据，`记` 转给 `工具\人格记忆.mjs`，`桥接同步` 手动对齐 routes。
- 记忆怎么落：**一律走工具** — `桌宠.mjs 记 --类 记忆|对话|待办 …` 落 `记忆\` / `对话\` / `_待办.md`，自动补索引、跑场景记忆闸门；`人格记忆.mjs 读 --词` 召回、`归档 --天 180` 搬老条目、`体检` 查索引孤儿。开关与「写前确认」在 ⚙ 设置 的「她怎么记事」里。

## 边界（写回复与写记忆都按这三条）

1. 对外一律先自报是 AI，不伪装真人。
2. 钱 / 承诺 / 个人信息，先说清再等人确认；不替用户在第三方平台登录、发言、下单。
3. 各业务场景的 `决策\`、`坑\` 归它们自己维护，人格层只读不改。
