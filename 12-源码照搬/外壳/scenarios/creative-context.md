## 大肥鱼怎么操作 Blender（唯一入口）

> 只用这条命令接口，⛔ 不自己拼 blender.exe 参数、不直连 GUI、不在壳外启停 Blender。

| 目的 | 命令 |
| --- | --- |
| 认环境（装没装 / 跑没跑 / 桥接通不通 / 工程根在哪） | `node 12-源码照搬\工具\Blender.mjs probe` |
| 后台跑一段 bpy 脚本（出模型 / 改材质 / 批量处理） | `node 12-源码照搬\工具\Blender.mjs run --script <脚本.py> [--blend <工程.blend>]` |
| 在用户正开着的 Blender 里实时执行（改当前场景、读对象、出图） | `node 12-源码照搬\工具\Blender.mjs exec --file <脚本.py>`（或 `--code "…"`） |
| 打开某个工程（带桥接，打开即可被 exec） | `node 12-源码照搬\工具\Blender.mjs open --blend <工程.blend>` |
| 出概念图 / 三视图 / 气氛图（**生图默认 Seedream**） | `node 12-源码照搬\工具\生图.mjs gen --prompt "<提示词>" --out "概念\<资产>\concept_<资产>_front.png" [--ref "概念\参考\<资产>-ref.png"] [--size 2K] [--n 2]`；模型默认 `doubao-seedream-4-5-251128`，key 取 `ARK_API_KEY` 或 `机器配置.json` 的 `arkApiKey`（`node 工具\生图.mjs set-key --key "ark-…"` 写入） |

**链路实测（2026-11-13，非推断）**：`probe` → 可执行来自机器配置 · 运行中 · 桥接通；`exec --code` 读回用户正开的场景 `3 objs: Camera, Cube, Light`；`run --script 工作区\创意工坊\_脚本\2026-11-13-验证-木箱.py` 后台出资产——`SM_Box_lo_v001` 54 面 / 108 三角 / 56 点 / 1 材质，`工程\_验证_木箱_lo_v001.blend` 430 KB、`输出\test\_验证_木箱_lo_v001.png` 960×540/32spp 渲染 27 s、`导出\_验证_木箱_lo_v001.glb` 9.4 KB。**结论：出模型/出图/出 GLB 是文件级真产物，不是话术。**
| 换 Blender 安装位 / 换工程根 | `node 12-源码照搬\工具\Blender.mjs set-exe --path "<blender.exe>"` / `set-dir --path "<目录>"` |

### 硬规矩

1. **先 probe 再动手**：`probe` 说没装就直说「本机没找到 Blender」，并把 `set-exe` 的用法给用户；⛔ 不猜路径、不擅自下载安装包。
2. **产物落工程根**：`.blend` / 渲染图 / `.glb` 一律写 `工作区\创意工坊\` 下的子目录（`工程\` `输出\` `导出\`），⛔ 不写盘根、桌面、C 盘临时目录。
3. **不覆盖用户工程**：同名 `.blend` 先看 mtime，要覆盖先问；`run` 产生的中间脚本放 `工作区\创意工坊\_脚本\`（带日期），别丢工程根顶层。
4. **实时 vs 后台分清楚**：用户正开着 Blender 改东西 → 用 `exec` 只做增量（加对象 / 改材质 / 读状态）；要整场景重建或长时间批量 → 用 `run --background`，⛔ 不在用户正编辑的会话里做破坏性重建。
5. **出图要能验**：渲染完把输出路径给用户，并说明分辨率 / 引擎 / 采样数；没出图就报错，不写「已完成」。
6. **本场景只碰 Blender 与工程文件**；改工作台代码、改面板、换会话 → 派给「程序开发」，不在这里动手。
