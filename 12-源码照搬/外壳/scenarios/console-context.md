# 工作台控制台 · 定位卡

- 场景 id：`console`
- 一句话：把「只能命令行」的工作台功能接出界面入口，配置与状态都指向真实那一份
- 面板：`外壳\scenarios\console.json`（**只 2 块**：`con-desk` 功能台 / `con-config` 管理总览）
- 实现：`外壳\功能台.js`（登记表 + 执行 + 探针 + 界面偏好），IPC `feature:list|run|status|kill|config:get|config:set`
- 记忆：`引擎数据\.dsh\场景记忆\工作台控制台\`

## 这个场景管什么

| 组 | 管什么 | 真配置在哪 |
| --- | --- | --- |
| 插件开关 | 省 token（compaction / command-compact）· 省 token 守卫 bundle · 记忆回响注入 | `引擎数据\.dsh\profiles\web\cordis.patch.yml`、`profiles\web\package.json` 的 `dsh.profile.bundles` |
| 记忆维护 | 近期记忆生成 · 人格记忆读/归档 · 通道记忆 · 场景记忆 check/索引/收工 · 项目记忆体检 | `引擎数据\.dsh\场景记忆\`、各项目 `memory\` |
| 自检与发布 | 发布前检查 · 桌宠自检 · 渲染自检 · 用量自检 · 外壳静态测试 · 环境自检 · 引擎升级后核对 · 打发布包 | 只读，产物在 `说明\` / 各自日志；出包写 `<out>\` |
| 协作与通道 | 人格引用同步（pet.json 的 pet-ai 为唯一真源）· 跨场景发消息 · 会话改名 | `外壳\scenarios\*.json`、`%USERPROFILE%\.dsh\qq-bridge.config.json` |

## 怎么找东西（认知层）

功能一多，靠记名字是记不住的。这个场景的界面按**「什么时候会用」**排，不按代码目录排：

| 档 | 判据 | 界面表现 |
| --- | --- | --- |
| `daily` 日常 | 每次开工 / 写记忆 / 查 token 时 | 目录里带「日常」标，默认选中第一条日常 |
| `weekly` 周期 | 每周、发布前、改完开关 | 无标 |
| `rare` 低频 | 只有出问题才想起来 | 目录里带「低频」标（不再折叠隐藏，列表可滚） |

- 只有两块。左边「功能台」= **左栏目录 + 右栏详情**（`group: "all"`，32 项全在这块），右边「管理总览」= **三页签**：配置（插件卡 / 配置源 / 工具策略 / 界面偏好 / 无配置项 / 清理）、最近（10 条操作）、日志（8 份 + 打开目录）。默认落在「配置」，页签记 `sessionStorage`（`fc.tab`）。
- **左栏目录**永远看得见：搜索框（跨全部组，功能名 / 用途 / 脚本名 / 按钮名都能搜）→ 分组 chips（全部 + 5 组，带项数）→ 条目列表；每条带状态点（绿 = 脚本在 / 红 = 脚本不在）、组名、「日常 / 低频」标、上次结果（✓/✗ + 多久前）。
- **右栏详情**一次只展开一个功能：名称 / 组 / 脚本 → 说明 → 配置位（见下表）→ 当前开关状态（后补，不挡卡片）→ 动作按钮（上次跑过的那条带 ✓/✗）→ 参数表单（一次只开一条动作，收起再开不丢已填值）→ 输出区（跑着有「停」，跑完给结论 + 全文日志）→「接着做」。
- **配置位四类**（32 项全部声明，不造假开关）：`plugin` 3 项（省 token / 守卫 / 记忆回响，显示真源 + 当前值，可「去改」并预填，改完重启整壳）；`machine` 1 项（环境自检，端口 / node / 路径只读，换机器先跑「环境适配」）；`external` 2 项（人格同步 / 桌宠运行时，只指路，真源在 pet.json / 桌宠设置 / qq-bridge）；`none` 26 项（只读检查或一次性动作，每项写明 `noWhy`，右栏折叠列出）。
- 选中项记在 `sessionStorage`（`fb.sel`）：刷新、关掉面板再开都停在上次那一项；找不到才退回第一条「日常」。
- 左下角是**可折叠**的「出什么事点什么（6）」：点开 6 条症状 → 选中那个功能，只跳转、**不代你执行**。默认收起，免得吃掉左栏三分之一高度。
- 频率写死在 `功能台.js` 的 `FREQ` 表里（一处真源，界面不自己猜）；症状表在 `TRIAGE` 表里。要调顺序改这两张表，别改渲染器。
- 右边「管理总览 · 最近」按时间倒序列 `recentCount` 条（默认 10；哪个功能 · 哪个动作 · 成没成 · 错在哪 · 共点过几次），读的是同一份 `功能台.json` 的 `last`，不另存。
- 想清理长期没人用的卡：`node 12-源码照搬\外壳\功能台.js --audit 90`（列出 90 天没点过的项，只读）。
- 「上次 ✓」与「什么时候用过」分开存：`last`/`hits` 是给人看的（配置面板可清），`seen` 是审计证据（清空不清它，`--audit` 读的就是它）。
- 配置值一律从真源读，功能台不自己解析 YAML：插件读脚本 `--json` 的结论，策略读 `外壳\data\工具策略.json`，界面偏好读 `外壳\data\功能台.json`。右栏只做「读 — 校验 — 调 setter」，写仍走左栏原动作。

## 硬约定

1. **不猜状态**：三个插件开关的「装没装 / 什么模式 / 当前阈值」一律跑脚本 `--status` / `--check --json`（`feature:status`，缓存秒数读 `工具策略.json` 的 `statusCacheSec`，默认 60），界面不另存一份影子状态。
2. **不进 shell**：`功能台.js` 用 `spawn(<真 node 可执行>, [脚本, ...参数])`，参数逐项进 argv；界面只能传登记表里声明过的输入项。⛔ 不用 `process.execPath`：主进程里它是 `electron.exe`，不带 `ELECTRON_RUN_AS_NODE` 就等于又起一个工作台，子进程不出输出（2026-11-18「一直读取中」的根因）。选法照 `main.js` 的 `toolNode()`：`DSH_NODE` → nvm → `ProgramFiles\nodejs` → PATH 的 `node`，都没有才退回 electron 的 node 模式。
3. **写操作连点两次**：`danger=write` 的动作第一次点只提醒，6 秒内再点一次才真跑（配置里可关，默认开）。
4. **破坏性动作多一道闸**：`danger=destructive`（出包、连引擎打、拆成分条、整理归档、沉淀定论）不看二次确认——必须**手打「确认」**两个字才解锁执行按钮，因为这几步会覆盖 / 搬运真实文件。
5. **登记表有门禁**：`scripts\测试.mjs` 的第 9 项会拦「没说明 / 没动作 / 脚本不在白名单目录 / 没声明配置位 / plugin 的动作对不上 / none 没说原因 / 症状表指向空卡」，加功能忘了写说明或配置位会直接测试失败。
6. **跑着的能停**：执行中右栏输出区有「停」，走 `feature:kill(id, actionId)` —— 只停这一条动作（同功能另一条不受影响），不碰别人的进程；超时与手动停走同一出口，结果写「已手动停掉」。
7. **全文落盘**：输出超过 `uiTextChars`（默认 6000）字会被界面截断，全文写 `外壳\data\历史\<功能>.<时间>.log`（每功能留 `logKeepPerFeature` 份，默认 20），输出区的「打开完整日志」直达；失败时标题行直接给原因（取输出最后 3 行）。单条动作抓取上限 `outputCapChars`（默认 4 万字），超了只砍**中间**（留头 `outputHeadChars` / 尾 `outputTailChars`，默认 2000 / 37000），尾部永远是真结尾 —— 别改成砍尾部，否则长日志的失败原因会取错。
8. **同时最多跑 `maxRunning` 条（默认 2）**：全局上限（不是只防同一条重复点），超了直接拒并提示先停一条；不排队。切完开关成功后探针缓存立刻作废，详情里的开关状态不会还是旧的。
9. **不启停引擎**：开关类改完只提示「重启整壳生效」——引擎生命周期归壳所有（⛔ 不在壳外 Stop/Start，token 会失效）。
10. **配置分三层**：插件真值写 profile patch / bundle 清单（改完重启整壳）；工具策略写 `外壳\data\工具策略.json`（状态缓存 / 并发 / 输出上限 / 日志保留 / 最近条数 / 日志列数，改完立即生效，缺文件用代码默认，超范围整组退回默认）；界面偏好写 `外壳\data\功能台.json`（本机、不入库）。配置面板（三页）里：配置页有插件卡、配置源（4 个）、策略编辑（9 个数字 + 保存 / 恢复默认）、界面偏好（`打开配置文件`）、无配置项 26 项折叠、`清空上次结果与计数`（`configSet({reset:true})`，只清 `last`/`hits`，不碰真实开关、不删日志、不清 `seen`）；日志页有 `打开目录`（`data\历史\`）与最近 `logListCount` 份日志列表（文件名 · 大小 · 点一行即开全文）。

## 排障口径

- 一条命令核全部按钮：`node 12-源码照搬\外壳\功能台.js --verify`（逐条动作查「脚本在 / 开关名对得上 / 只读真跑」；写与破坏性只核开关名、不实跑；exit 1 = 有坏项，`--json` 给机器读）。
- 面板显示「这个宿主没有功能台」= preload 还是旧的 ⇒ 重启一次工作台。
- 面板显示「脚本不在」= 对应 `.mjs` 被移走/改名 ⇒ 先看 `node 12-源码照搬\外壳\功能台.js`，它会逐项打 ✓/✗。
- 跑出来「退出码 N」= 脚本自己的判据没过，标题行已把原因提上来（输出最后 3 行），全文在「打开完整日志」；⛔ 不要把失败当成功。
- 跑太久 / 卡住：点卡片上的「停」。封装、发布前检查这类十几分钟的动作别直接关面板。
- 开关改完没生效：先确认是**重启整壳**（不是只重启引擎），再看 patch 里那段 `# >>> 省token` 标记在不在。
