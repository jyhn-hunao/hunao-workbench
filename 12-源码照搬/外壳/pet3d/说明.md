# 桌宠 3D · 接口约定（2026-11-18 已接入）

> 状态：**已接入 `pet-3d` 面板**（`@site:/pet3d/`，three.js + GLB，四态跟随人格会话）。房间 / 室外（`room.glb` / `yard.glb`）仍未做；下文是素材与状态约定。

## 素材从哪来

- 概念设定：`12-源码照搬\外壳\pet3d\概念\`（角色三视图 / 比例 / 服装细节，建模依据就这几张）
- 建模：不在本仓做，仓库只收最终模型；概念图与模型同目录，方便对照
- 导出格式：**glTF 二进制 `.glb`**（带骨骼动画、贴图、PBR 材质，一个文件搬走）
  - 身体：`body.glb`（含骨骼与 `idle` 循环；`walk` / `talk` / 表情还没做）
  - 房间：`room.glb`；室外：`yard.glb`（可后补）
  - 贴图与音频：与 glb 同目录，别塞绝对路径
- 落点：`12-源码照搬\外壳\pet3d\模型\`（本目录，未建则先建）

## 工作台怎么显示（现状）

- 面板：`pet.json` 的 `pet-3d`，类型 `embed`，URL `@site:/pet3d/`（端口不写死）；页面 + 模型 + vendor 静态资源在 `外壳\pet3d\`，状态端点 `/pet3d/state`
- 渲染：three.js + `GLTFLoader`，toon 材质 + 倒置外壳描边；`requestAnimationFrame` 跟随刷新率
- **渲染总开关**（2026-11-18 用户要求，治常驻渲染卡顿）：面板右上「设置」→「3D 渲染」，落 `localStorage.pet3d_render`（默认开、会记住）。关掉走 `stopRender()`：取消 rAF、停 `/pet3d/state` 轮询、`renderer.clear()` 清掉最后一帧；关闭态藏画布与徽标，整页留「开启 3D 渲染」按钮。页面不可见（最小化 / 切走）时也临时停帧，回来按开关恢复，不动用户的选择
- **视角交互**（2026-11-18）：画布支持左键/单指拖动旋转、滚轮/双指捏合缩放；右上「设置」→「视角 · 复位」回正。只改相机，不动模型与状态；关渲染时画布隐藏，交互随之停。相机有角度和距离限制，不会翻到地面以下或缩进模型里
- 依赖：three.js 属新增依赖，**提交时必须写明理由**（AGENTS.md §4「依赖」）
- 状态驱动（接口，先定字段不改实现）：
  | 状态 | 来源 | 表现 |
  |---|---|---|
  | `idle` | 无人说话 | 呼吸 / 头部轻摆（眨眼待面部通道，见「明确不做」） |
  | `thinking` | 会话里出现 `turn/start` 且无输出 | 微微转头、停顿 |
  | `speaking` | 出现 `assistant/message` 且正在流式输出 | 头部小幅摆动（口型待面部通道，见「明确不做」） |
  | `listening` | 用户输入中 / 语音输入 | 面向镜头、轻微前倾 |
- 状态从会话事件推：复用 `外壳\社交.js` 的 `readEvents` / `messagesOf`（只读 transcript），⛔ 不新增第二套解析

## 明确不做（现在）

- 不做房间 / 室外两个 GLB（目录先留空位）
- 不做常驻小窗、语音、动作系统
- 面部表情 / 口型暂不做：GLB 只有 31 根身体骨、0 个形态键，五官是固定几何（嘴基型就是张开）；要做得先在建模端加面部骨或 shape keys（2026-11-18 用户决定先不加）
- 不把 3D 资源放进 `引擎数据\`（那是引擎 home，2D 面板与记忆才在那）
