# 大肥鱼·Live2D PSD 拆分规范（手工版）

## 0. 结论先说

- 不要再用 AI 生成的 4 层/9 层底图当分层源。白边、半透明头纱、脖子白缝都是自动抠图留下的。
- 以原图 `07-气氛图.png` 为唯一颜色来源：**复制原图 → 每层加蒙版 → 黑笔刷掉不要的**，不要用魔棒删白底。
- 先按 **9 层**拆；如果只想先跑通，拆到 `01`～`04` + `08` + `09` 六层也能跑，眼/嘴以后再加。
- 画布必须是 **1254×1881，RGBA/8bit，无 Background 图层**。
- 模板已生成：`大肥鱼-半身-分层模板.psd`。里面 `00_reference` 是隐藏的原图参考层，描线时打开眼睛图标，导出前关掉。

## 1. 层序（从下到上，PSD 里就是 Layer 1 → Layer 9）

| 顺序 | 层名 | 只放什么 | 绝对不要放什么 |
|---|---|---|---|
| 1 | `01_tail` | 鲸鱼尾巴整体，尾根到右边缘 | 身体、裙子、后发 |
| 2 | `02_hair_back` | 身体后面的长发、后脑勺下方的头发 | 刘海、脸颊两侧垂到胸前的长发 |
| 3 | `03_body` | 脖子以下全部：衣领、黑裙、白围裙、手臂、手、腿、鞋、领结、袖口 | 脸、耳朵、头发、尾巴、头饰 |
| 4 | `04_head_base` | 脸、耳朵、下巴、脖子前侧皮肤 | 刘海、后发、头饰、眼、嘴、腮红以外的头发 |
| 5 | `05_eye_L` | 左眼整只：眼白、瞳孔、睫毛、双眼皮 | 眉毛、刘海、脸皮 |
| 6 | `06_eye_R` | 右眼整只 | 同上 |
| 7 | `07_mouth` | 嘴：嘴唇、口腔、舌头、牙齿 | 下巴、腮红、脸皮 |
| 8 | `08_hair_front` | 刘海、鬓角、垂到胸前的侧发、呆毛 | 后发、头饰、脸 |
| 9 | `09_headwear` | 白色女仆头饰/蕾丝、两个蓝蝴蝶结、鲸鱼耳鳍 | 头发、脸、后发 |

> 眼/嘴层如果暂时不做：把 `05`～`07` 留空，Cubism 里 `autoBlink` 必须保持 `false`。  
> 但 `04_head_base` 里要保留原图的完整眼睛和嘴，不能挖空，否则静态脸会缺五官。

## 2. PS 里怎么拆（每层都按这个顺序）

1. 打开模板 PSD，点亮 `00_reference`（原图参考层），锁定它，防止误画。
2. 新建/选中目标层，用 **矩形选框** 或 **套索** 把原图对应区域复制过来；或者直接把原图整张复制进目标层。
3. 给目标层加 **图层蒙版**，用 **硬度 90%～100% 的黑色画笔** 把不属于这层的部分涂掉。  
   - 不要用 `魔棒 → Delete`：白底会留一圈白边。  
   - 不要用 `选择并遮住` 的羽化/平滑 > 1px：会留下半透明白膜。
4. 边缘修整用 **白色画笔** 在蒙版上补回来，黑色画笔修出去；画笔硬度保持 90% 以上。
5. 每拆完一层，单独关掉其它层，在 **黑底** 和 **50% 灰底** 各看一次，检查白边/半透明。
6. 最后隐藏 `00_reference`，另存为 `大肥鱼-半身-手工九层.psd`。

## 3. 你现在截图里的三类问题，分别怎么修

### 3.1 头饰/头发外圈那层半透明白膜

- 现象：棋盘格里能看到一圈淡白色壳，像玻璃罩。
- 原因：自动去白边把白色蕾丝和轮廓光做成了半透明 alpha。
- 修法：`09_headwear` 里的白蕾丝必须是 **不透明白色**；蒙版上把 alpha 补回 100%。  
  原图里白色蕾丝本来就是实的，不是纱。只有头发高光可以保留半透明。

### 3.2 后发右侧的白色/蓝色细边

- 现象：头发外缘有一条 1～3px 的白边或蓝边。
- 修法：在 `02_hair_back` 的蒙版上，用黑色硬画笔沿外轮廓往里收 1～2px；不要用羽化。  
  如果原图本身有轮廓光，保留 **头发颜色** 的亮边，不要把亮边涂成纯白。

### 3.3 脖子/衣领处的白缝

- 现象：头层和身体层接缝处出现一条白线/透明缝。
- 原因：两层刚好切在可见边缘，没有重叠。
- 修法：让 `03_body` 的衣领和脖子 **向上多留 3～5px**，塞到 `04_head_base` 下面；  
  `04_head_base` 的下巴边缘 **向下多留 2～3px**，盖住身体。两层必须重叠，不能对接。

## 4. 拆层时的硬规则

- **重叠优先**：所有关节（脖子、肩膀、手腕、尾根、发根）都多留 3～5px，Live2D 旋转时才不会露缝。
- **不要羽化**：除头发高光/头纱外，所有 alpha 边缘保持硬边；Live2D 网格会放大软边，变成白雾。
- **颜色不改**：直接从原图复制，不要重新上色、不要滤镜、不要 AI 重画。
- **单层可多块**：比如 `08_hair_front` 可以同时有刘海、左鬓角、右鬓角、呆毛；Cubism 自动网格会分岛，不影响。
- **尾巴和后发必须在身体下面**：层序错了，Live2D 里会穿帮。
- **脸不要挖空**：`04_head_base` 必须包含完整五官；眼/嘴层是盖在脸上的，不是把脸挖洞。

## 5. 验收（拆完必须过）

- [ ] 1254×1881，RGBA，8bit，无 Background。
- [ ] 9 层名称与层序和上表完全一致。
- [ ] 关掉 `00_reference` 后，9 层叠加与原图逐像素对比，颜色/位置无偏移。
- [ ] 黑底无白边，50% 灰底无半透明白膜。
- [ ] 400% 放大检查：脖子、衣领、发梢、尾根没有透明缝。
- [ ] 每层单独显示时，没有混入其它部件（尤其头层不能带身体，身体层不能带脸）。
- [ ] 眼/嘴层如果做了，位置能盖住 `04_head_base` 的原五官，不跑位。

## 6. 导出与 Cubism 导入

- 保存：`文件 → 另存为 → PSD`，勾选“最大兼容”，颜色模式 RGB/8bit。
- Cubism 导入 PSD 时选 **`从PSD文件创建模型（5.2版本之前的混合模式）`**，不要选 5.3 新混合模式。
- 导入后先核对部件顺序：`09_headwear` 在最上，`01_tail` 在最下。
- 绑定层级建议：
  - `BodyRot` ← `03_body`
  - `BodyRot` ← `HeadRot` ← `04_head_base`、`05_eye_L`、`06_eye_R`、`07_mouth`、`08_hair_front`、`09_headwear`
  - `BodyRot` ← `TailRot` ← `01_tail`
  - `02_hair_back` 放 `BodyRot` 下、`HeadRot` 后面（或跟随 `HeadRot`，看摆动效果）。
- 旋转中心：
  - `HeadRot` 脖子根部：约 `x=602, y=903`（画布 48% / 48%）
  - `BodyRot` 两脚中间：约 `x=602, y=1693`（48% / 90%）
  - `TailRot` 尾根：约 `x=815, y=1354`（65% / 72%）
