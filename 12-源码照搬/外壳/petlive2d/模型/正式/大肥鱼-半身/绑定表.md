## 2. 变形器层级

```
Root
└─ BodyRot                 （身体左右倾）
   ├─ 03_body              （身体）
   ├─ HeadRot              （头左右转 / 点头 / 歪头）
   │  ├─ 04_head           （头部）
   │  └─ 02_hair_back      （后发，跟着头走）
   └─ TailRot              （尾巴左右摆，可选）
      └─ 01_tail           （尾巴）
```

- `HeadRot` 必须是 `BodyRot` 的子级：身体晃的时候头要跟着走。
- `02_hair_back` 挂在 `HeadRot` 下：头转，后发跟着转；但绘制顺序仍在身体后面。
- `TailRot` 挂在 `BodyRot` 下：身体晃，尾巴跟着；再做独立摆尾。
- 绘制顺序（部件面板从上到下）：`04_head` → `03_body` → `02_hair_back` → `01_tail`。这个顺序不要反，反了后发会盖脸。

## 3. 变形器位置与支点

| 变形器 | 类型 | 包住谁 | 支点放在哪 | 初始角度 |
| --- | --- | --- | --- | --- |
| `HeadRot` | 旋转变形器 | 头 + 头饰 + 长发 | 脖子根部，画布约 **48% 宽 / 48% 高** | 0 |
| `BodyRot` | 旋转变形器 | 身体（裙 / 腿 / 鞋） | 两脚中间，画布约 **48% 宽 / 90% 高** | 0 |
| `TailRot` | 旋转变形器 | 尾巴 | 尾根，画布约 **65% 宽 / 72% 高** | 0 |

- 支点不是画布中心，是「关节」。头绕脖子转，身体绕脚底转，尾巴绕尾根转。
- 首版角度别大：头 ±10°、身体 ±5°、尾巴 ±8°。角度一大，脖子和裙摆接缝会露。
- 百分比是给你在画布上找位置用的；Cubism 里直接拖红条根部的小圆点到对应位置。

## 4. 参数表

> 参数 ID 必须一模一样，大小写不能错。Cubism 里没有的，按「新建参数」补，范围按下表填。

| 优先级 | 变形器 | 参数 ID | 范围 | 默认 | 关键帧怎么摆 | 作用 |
| --- | --- | --- | --- | --- | --- | --- |
| P0 先做 | `HeadRot` | `ParamAngleZ` | -30 ~ 30 | 0 | -30 → 角度 Z **-10°**；0 → 0；+30 → **+10°** | 歪头（运行时 thinking / speaking 会推） |
| P0 先做 | `BodyRot` | `ParamBodyAngleX` | -10 ~ 10 | 0 | -10 → 角度 Z **-5°**；0 → 0；+10 → **+5°** | 身体左右倾（运行时 listening 会推） |
| P1 再做 | `HeadRot` | `ParamAngleX` | -30 ~ 30 | 0 | -30 → 角度 Y **-15°**；0 → 0；+30 → **+15°** | 左右转头（视线跟随时用） |
| P1 再做 | `HeadRot` | `ParamAngleY` | -30 ~ 30 | 0 | -30 → 角度 X **-8°**；0 → 0；+30 → **+8°** | 点头 / 抬头（运行时 listening 会推） |
| P2 可选 | `TailRot` | `ParamTailAngleZ` | -15 ~ 15 | 0 | -15 → 角度 Z **-8°**；0 → 0；+15 → **+8°** | 尾巴左右摆 |

### 参数与旋转轴对应（照这个填，不要凭感觉）

| 参数 | 在旋转变形器里改哪个角度 | 说明 |
| --- | --- | --- |
| `ParamAngleX` | `角度 Y` | 头左右转（水平转头） |
| `ParamAngleY` | `角度 X` | 头上下点（点头 / 抬头） |
| `ParamAngleZ` | `角度 Z` | 头左右歪（倾斜） |
| `ParamBodyAngleX` | `角度 Z` | 身体左右倾 |
| `ParamTailAngleZ` | `角度 Z` | 尾巴左右摆 |

- 先只做 P0 两个参数，把模型拖到「能动」；再加 P1。
- 每个参数用参数面板的「插入 3 个键」/「三点关键帧」，生成最小 / 中间 / 最大三个点。
- 点最左的关键帧 → 参数值填 -30；再到画布把 `HeadRot` 的 `角度 Z` 改成 -10；点中间 → 0 / 0；点最右 → +30 / +10。
- 如果参数面板里本来就有 `ParamAngleX/Y/Z`，直接用，不用新建。

## 5. 网格建议

| 图层 | 自动网格点间隔 | 说明 |
| --- | --- | --- |
| `04_head` | 100 | 头部基本是刚体，只做整体旋转，不需要密网 |
| `03_body` | 100 | 身体只做整体倾斜；想呼吸起伏再单独加弯曲变形器 |
| `02_hair_back` | 100 | 跟着头走；想头发飘再加弯曲变形器 |
| `01_tail` | 80 | 尾巴要弯，密一点 |

- `Ctrl+A` → 工具栏「自动网格生成」→ 默认值 → 点一下数值框按 Enter。
- 自动网格后如果边缘被拉裂，选中那一层单独再生成一次，点间隔改 60。
- 不要手动去挪脸的五官顶点；脸是原图像素，挪了就会崩。

## 6. 与当前运行时的兼容

`petlive2d/app.js` 现在只主动推这些参数：

| 参数 | 运行时会不会推 | 这版模型有没有 |
| --- | --- | --- |
| `ParamAngleX` / `ParamAngleY` / `ParamAngleZ` | 会（视线 / 四态） | 有（P0/P1） |
| `ParamBodyAngleX` | 会（listening） | 有（P0） |
| `ParamBodyAngleZ` | 会列在参数表里，但当前没推 | 可不做 |
| `ParamEyeLOpen` / `ParamEyeROpen` | 会（自动眨眼，默认关） | **没有**，运行时会自动跳过 |
| `ParamMouthOpenY` / `ParamMouthForm` | 会（说话） | **没有**，运行时会自动跳过 |
| `ParamBreath` | 会列在参数表里，但当前没推 | 可不做 |
| `ParamTailAngleZ` | **当前不读** | 建了也不会动；要让尾巴独立摆，得再加一行代码 |

- 首版 `autoBlink` 必须保持 `false`；没有眼层，开了也不会眨。
- 没有嘴层，说话时嘴不会动；这是这版取舍，不是绑定错。
- 尾巴首版跟着身体走；独立摆尾是下一步。
