## 第 2 步：自动生成网格

1. 在画布上点一下，按 `Ctrl+A`，把 4 个图形网格全选中。
2. 点工具栏的 **「自动网格生成」**（快捷键 `Ctrl+Shift+A`）。
3. 弹出对话框，先用默认值：
   - 点的间隔（外侧）：`100`
   - 点的间隔（内侧）：`100`
   - 边界余量：`20`
4. 在任意一个数值框里点一下，按 `Enter`，等它生成。
5. 点对话框右上角 `×` 关闭。

### 如果网格碎了 / 纹理消失

- 选中出问题的那一层，单独再点一次「自动网格生成」，把「点的间隔」改成 `60`，再按 `Enter`。
- 头部 `04_head` 是原图像素，**不要手动去挪脸上的顶点**；脸崩了就是这里挪的。
- 尾巴 `01_tail` 可以用 `80`，弯起来更顺。

## 第 3 步：创建 3 个旋转变形器

> 旋转变形器就是工具栏上那个「红色圆头棒」图标；弯曲变形器是灰色方块。这版只用旋转变形器。

### 3.1 建 `HeadRot`（头）

1. 在「部件」面板点 `04_head`，画布上选中头部。
2. 点菜单 `建模 → 创建旋转变形器`（或工具栏红色圆头棒图标）。
3. 弹出「创建旋转变形器」对话框，填：
   - 插入目标部件：`Root`
   - 名称：`HeadRot`
   - 追加目标：选 **`选择对象的父级`**（因为刚才选中了 `04_head`，这样新框会自动把头部装进去）
4. 点 `创建`。
5. 画布上出现一根红条。把红条根部的小圆点拖到 **脖子根部**（画布大约 48% 宽、48% 高的位置）。
6. 红条长度拉到能盖住整个头（头顶到下巴）。长度不够就按住 `Alt` 再拖红条前端。
7. 点一下 `04_head`，右边「检查器」的「变形器」应该已经是 `HeadRot`；是就说明挂好了，不用再手动挂。

### 3.2 建 `BodyRot`（身体）

1. 在「部件」面板点 `03_body`。
2. 同样 `建模 → 创建旋转变形器`。
3. 填：
   - 插入目标部件：`Root`
   - 名称：`BodyRot`
   - 追加目标：`选择对象的父级`（选着 `03_body` 时创建，身体会自动装进去）
4. 点 `创建`。
5. 把红条根部拖到 **两脚中间**（画布大约 48% 宽、90% 高的位置），长度拉到腰。

### 3.3 建 `TailRot`（尾巴，可选）

1. 点 `01_tail`。
2. `建模 → 创建旋转变形器`。
3. 填：
   - 插入目标部件：`Root`
   - 名称：`TailRot`
   - 追加目标：`选择对象的父级`（选着 `01_tail` 时创建，尾巴会自动装进去）
4. 把红条根部拖到 **尾根**（画布大约 65% 宽、72% 高的位置），长度顺着尾巴方向。
5. 如果这步觉得麻烦，可以先跳过；不影响头和身体。后面想加再回来。

## 第 4 步：设置父子关系（最关键）

> 目标层级：
> ```
> BodyRot
> ├─ 03_body
> ├─ HeadRot
> │  ├─ 04_head
> │  └─ 02_hair_back
> └─ TailRot
>    └─ 01_tail
> ```

### 4.1 核对 4 个部件有没有装进框

> 如果第 3 步创建时选的是 `选择对象的父级`，这一步应该已经自动完成。下面只是核对表；显示已经是右边这个，就不用再拖。

在「部件」面板选中部件，右边「检查器」面板找到 **「变形器」** 下拉框：

| 选中的部件 | 检查器「变形器」选谁 |
| --- | --- |
| `03_body` | `BodyRot` |
| `04_head` | `HeadRot` |
| `02_hair_back` | `HeadRot` |
| `01_tail` | `TailRot` |

- 下拉框里如果没有你要的变形器，说明第 3 步没建成功，回去补建。
- 选完以后，画布上该部件会被红条/灰框包住。

### 4.2 把变形器再挂到变形器

1. 在左下「变形器」面板选中 `HeadRot`。
2. 右边「检查器」找到 **「父级变形器」**，选 `BodyRot`。
3. 选中 `TailRot`，父级变形器选 `BodyRot`。
4. 检查「变形器」面板的树，应该和上面目标层级一模一样。

### 4.3 检查绘制顺序

- 「部件」面板从上到下仍然是：`04_head` → `03_body` → `02_hair_back` → `01_tail`。
- 父子关系只管「谁带着谁动」，绘制顺序只管「谁盖谁」；两个都要对。

## 第 5 步：先做 2 个参数，让模型动起来

> 先只做 `ParamAngleZ`（歪头）和 `ParamBodyAngleX`（身体左右倾）。这两个能动，再补其他的。

### 5.1 歪头 `ParamAngleZ`

1. 在「变形器」面板选中 `HeadRot`。
2. 看下方「参数」面板，找到 `ParamAngleZ`。
   - 如果没有：点参数面板的 `+`（新建参数），ID 填 `ParamAngleZ`，最小 `-30`，最大 `30`，默认 `0`。
3. 点亮 `ParamAngleZ` 这一行，点参数面板顶部的 **「插入 3 个键」**（有的界面叫「三点关键帧」）。
4. 这一行会出现 3 个关键点：左、中、右。
5. 点 **最左边** 的点，把参数值填成 `-30`；再到画布上把 `HeadRot` 的 **「角度 Z」** 改成 `-10`。
6. 点 **中间** 的点，参数值 `0`，角度 `0`。
7. 点 **最右边** 的点，参数值 `+30`，角度 `+10`。
8. 拖 `ParamAngleZ` 的滑块，从头到尾拉一遍：头应该左右歪。

### 5.2 身体左右倾 `ParamBodyAngleX`

1. 选中 `BodyRot`。
2. 找到 `ParamBodyAngleX`；没有就新建，最小 `-10`，最大 `10`，默认 `0`。
3. 同样「插入 3 个键」。
4. 左点：参数 `-10`，`BodyRot` 的 `角度 Z` 改 `-5`。
5. 中点：`0` / `0`。
6. 右点：`+10` / `+5`。
7. 拖滑块：身体应该左右倾，头要跟着一起走。

### 5.3 如果拖滑块不动

按顺序查这 4 条：

1. 参数 ID 是不是一字不差：`ParamAngleZ`，不是 `ParamAnglez`、`ParamAngle Z`。
2. 这个参数是不是真的插了 3 个键；只改滑块没插键，等于没绑定。
3. 部件是不是挂在变形器下：检查器「变形器」下拉框要有名字。
4. `HeadRot` 的父级是不是 `BodyRot`；不是就头不跟着身体。

## 第 6 步：补 P1 参数（做完 P0 再回来）

### 6.1 左右转头 `ParamAngleX`

1. 选中 `HeadRot`。
2. `ParamAngleX` 插 3 个键：`-30` / `0` / `+30`。
3. 左点：`角度 Y = -15`；中点：`0`；右点：`角度 Y = +15`。
4. 拖滑块：头左右转，不是歪头。

### 6.2 点头 / 抬头 `ParamAngleY`

1. 选中 `HeadRot`。
2. `ParamAngleY` 插 3 个键：`-30` / `0` / `+30`。
3. 左点：`角度 X = -8`；中点：`0`；右点：`角度 X = +8`。
4. 拖滑块：头上下点。

### 6.3 尾巴 `ParamTailAngleZ`（可选）

1. 选中 `TailRot`。
2. 新建 `ParamTailAngleZ`，最小 `-15`，最大 `15`，默认 `0`。
3. 插 3 个键：`-15` / `0` / `+15`。
4. 左点：`角度 Z = -8`；中点：`0`；右点：`角度 Z = +8`。
5. 当前工作台运行时不读这个参数，所以建了也先不会自动摆；先确认 Cubism 里手动拖能动。

## 常见问题

| 现象 | 最可能的原因 | 怎么处理 |
| --- | --- | --- |
| 导入后四个白底矩形 | PSD 透明没读进去 | 停，截图发我；不要继续绑 |
| 部件面板顺序反了 | PSD 层顺序 / 导入顺序 | 把 `04_head` 拖到最上，`01_tail` 拖到最下 |
| 拖参数头不动 | 参数没插键 / 部件没挂变形器 / ID 写错 | 按第 5.3 条查 4 项 |
| 头动但后发不动 | `02_hair_back` 没挂 `HeadRot` | 检查器「变形器」选 `HeadRot` |
| 身体动但头不动 | `HeadRot` 没挂 `BodyRot` | 检查器「父级变形器」选 `BodyRot` |
| 头一转脖子裂开 | 角度太大 / 脖子没补层 | 头角度压到 ±10°；首版先接受 |
| 导出报「物理设置不正确」 | 勾了 physics3 但没做物理 | 取消 `物理运算设置文件` 勾选 |
| 导出后运行时 404 | `model3.json` 路径不对 / 纹理文件夹不在 | 确认 `当前.json` 的 `model` 指向真实文件；纹理文件夹和 model3 同级 |
| 模型太大 / 太小 | `heightRatio` 不合适 | 改 `0.75` ~ `1.0` |
| 眼睛不眨 / 说话嘴不动 | 首版没有眼层和嘴层 | 正常，不是绑定错；下一版再拆 |
| 尾巴不自动摆 | 运行时不读 `ParamTailAngleZ` | 首版尾巴跟着身体；要独立摆尾告诉我加代码 |

## 这版为什么只有 4 层

- 9 层 AI 拆脸试过：右眼跑到脸颊、左眼出现两个眼形、嘴层带出发丝、前发盖脸。硬交会变成「贴假脸」。
- 现在头部直接用原图像素，脸和五官 100% 是概念图原样；AI 只负责身体、后发、尾巴。
- 4 层够先把「厚涂感 + 能动」跑起来；眼、嘴、前发是下一版的事，不在这一版硬做烂图。
