# petlive2d · 模型目录约定

> 页面只认 `模型\当前.json` 这一份清单；换模型 = 改清单，不用改代码。
> 两种模式：当前用 **Cubism**（`model` 指向 `.model3.json`）；`"type": "layered"`（分层 PNG 运行时骨骼）保留为没导出 Cubism 时的兜底。

## 当前模型

- 清单：`模型\当前.json`，`type: "cubism4"`。
- 模型：`正式\大肥鱼-半身\大肥鱼-半身.model3.json`。
- 导出：Cubism 5.3 Editor，兼容目标 `SDK 4.2 / Cubism 4.2`，纹理 `2048×2048`。
- 七层：头 / 右臂 / 左臂 / 身体 / 右腿 / 左腿 / 尾巴；参数表里有角度、眼开闭/眼笑、眼珠、眉、嘴、脸颊、身体、呼吸、头发摇动，但**实际 keyform 全为 0**。
- 导出检查（2026-11-21）：`大肥鱼-半身.moc3` 里 27 个参数的 keyCount 都是 0，7 个 drawable 都是 4 顶点全画布 quad，没有 parts；也就是说 `ParamEyeLOpen` / `ParamMouthOpenY` / `ParamBreath` 改了也不会产生任何形变。页面因此改成**切换脸部贴图变体**补眨眼 / 口型，整体呼吸 / 摇摆由 Pixi 容器补（`app.js` 的 `updateFace` / `animateModelBody`）。
- `autoBlink: true`：由页面按 2.5–5.5 秒随机节奏切 `blink` 图集；要让眼/嘴真正被 Cubism 参数驱动，需要回 Cubism 工程给眼、嘴、头做网格与 keyform，改页面解决不了。
- `大肥鱼-半身.face/`：`blink.png`、`talk.png`、`talk2.png`、`blink_talk.png` 四张 **2048×2048** 变体，由 `_工具/19-生成脸动纹理.py` 从 2048 原图集生成；只改 head 那一格，其他格原样复制。`blink` / `blink_talk` 同时闭**两只眼**（大眼 + 左侧被刘海半遮的小眼），避免只闭一只造成“单眼 wink”。

## 目录

```
petlive2d/
  模型/
    当前.json          ← 页面读这一份（必填 model 字段）
    正式/              ← 你的正式模型放这里（一个角色一个目录）
      <角色名>/
        <角色名>.model3.json
        <角色名>.moc3
        *.png / *.physics3.json / *.pose3.json
        motions/*.motion3.json
        expressions/*.exp3.json
    示例/Hiyori/       ← 官方示例，只在本机验证管线（.gitignore 已挡，不入库）
```

## 当前.json 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `model` | 是 | `.model3.json` 的相对路径（相对本文件，例：`正式/大肥鱼/大肥鱼.model3.json`） |
| `label` | 否 | 左上角模型名与设置页显示名 |
| `heightRatio` | 否 | 模型占画面高度的比例，默认 `0.92` |
| `fps` | 否 | 渲染帧率上限，默认 `30`；想更顺可写 `60` |
| `motions` | 否 | 四态各自的**动作组名**：`idle` / `thinking` / `speaking` / `listening`；可写字符串或字符串数组（取第一个） |
| `expressions` | 否 | 四态各自的**表情名**（Cubism 的 `.exp3.json` 名，不带后缀） |
| `tapMotion` | 否 | 单击宠物时播的动作组（例：`TapBody`） |
| `autoBlink` | 否 | 模型自带眨眼时设 `false`；模型没有眨眼动作才设 `true`，由页面补眨眼 |
| `faceTextures` | 否 | 脸部贴图变体，四个键 `blink` / `talk` / `talk2` / `blinkTalk`，路径相对本文件；缺省则不眨眼、不说话张嘴；仅在 moc3 参数无 keyform 时用 |

## 分层骨骼模式（备用，不依赖 Cubism 导出）

不经过 Cubism：七张同尺寸透明 PNG 按支点旋转，手脚各自独立。

| 字段 | 说明 |
|---|---|
| `type` | 固定 `"layered"` |
| `canvas` | `[宽, 高]`，必须与七张 PNG 原尺寸一致（当前 1254×1881） |
| `layers[].name` | `tail` / `legL` / `legR` / `body` / `armL` / `armR` / `head` |
| `layers[].src` | PNG 相对路径（相对 `当前.json`） |
| `layers[].pivot` | 旋转支点画布坐标；尾根、髋、腰、肩、脖子 |
| `heightRatio` / `fps` | 同 Cubism 模式 |

层序即 `layers` 数组顺序：尾巴 → 左腿 → 右腿 → 身体 → 左臂 → 右臂 → 头。
`autoBlink`、`tapMotion` 在分层模式下不用填；单击触发挥手/踢脚。

## Cubism 导出

1. Cubism Editor 里做好模型后，先按 `Ctrl+T` 生成纹理集（新模型第一次导出前必须做，否则会提示「纹理集生成后调用」），再 `文件 → 输出运行时文件 → 导出为moc3文件`。
2. 输出版本选 `SDK 4.2 / Cubism 4.2`（当前 `pixi-live2d-display` 是 cubism4 运行时；5.3 的 moc3 不保证兼容）。
3. 输出会包含 `.model3.json`、`.moc3`、贴图；有物理/动作/表情时才额外带 `physics3.json`、`motions/`、`expressions/`。
4. 整个导出目录原样放进 `模型\正式\<角色名>\`，再把 `当前.json` 的 `model` 指到那份 `.model3.json`。
5. 路径一律相对，⛔ 不要写 `C:\` 开头的绝对路径（换机器会失效）。

> 旧「头部整层」模型没有独立眼/嘴层，`autoBlink` 必须保持 `false`。当前七层模型参数表齐全，但 keyform 为 0，所以保留 `autoBlink: true` 走贴图变体；等 Cubism 工程补出眼/嘴 keyform 后，再把这些参数动画切回真参数驱动。

## 四态怎么对上

- `idle`：无人说话；容器轻微呼吸、左右慢摆，眼睛按随机节奏眨。
- `thinking`：会话在跑、还没输出；容器歪一点、摆幅稍大。
- `speaking`：正在流式输出；页面按时间切 `talk` / `talk2` 口型，容器有轻微点头。
- `listening`：最近有人输入；容器向后靠一点，表达“在听”。
