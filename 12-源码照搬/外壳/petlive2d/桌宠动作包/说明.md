# 大肥鱼 · dsh-pet 桌面动作包（A 方案）

> 目标：完整使用 `dsh-pet 0.4.9` 的桌面身体功能（透明小窗、拖拽抛掷、点击回应、随机小动作、走动、工作状态、睡觉、气泡），只把形象换成大肥鱼。
> 不做实时 Live2D 桌面渲染；工作台里的 `pet-live2d` 参数骨骼面板保持原样。

## 一、方案边界

- **桌面**：640×360 预烘焙 VP9-alpha WebM，符合 dsh-pet 的舞台契约（`HIT_BOX x=200–440 / y=50–335`、`FEET_Y=330`）。
- **面板**：继续走本仓的 9 层 PNG + 实时参数，不替换、不降级。
- **代价**：桌面没有实时视线跟随、实时口型、逐像素原画保真；这些只有面板里有。桌面动作是 30fps 的烘焙片，播放时由 dsh-pet 做交叉淡入和朝向镜像。
- **不做**：不 fork dsh-pet 渲染层，不把 moc3 塞进它的视频舞台；`balance` / `baifan` 不接（余额与账本仍归工作台）。

## 二、文件结构

```
桌宠动作包/
├─ 烘焙/
│  ├─ 骨骼.py       # 9 层 PNG → 640×360 舞台，离线骨骼与道具合成
│  ├─ 动作.py       # 41 段动作函数 + CLIPS 注册表
│  └─ 烘焙.py       # 多进程渲染 PNG → libvpx-vp9 alpha WebM
├─ 素材/道具/        # Seedream 5.5 生成的透明底 Q 版道具
├─ webm/            # 41 段成品，约 8.36 MB
├─ 动作清单.json     # 每段时长、帧数、体积
├─ fantuan-config.json  # dsh-pet 文件宠物条目
└─ fantuan-avatar.png   # 对话头像 512×512
```

安装到 dsh-pet 后：

```
引擎数据\.dsh\dsh-pet\pet\
├─ fantuan-config.json
├─ fantuan-avatar.png
└─ fantuan-animation\webm\*.webm
```

## 四、构建与安装

```powershell
cd 12-源码照搬\外壳\petlive2d\桌宠动作包\烘焙
python 烘焙.py --workers 4          # 全量；--only idle_breathe 只烘一段
python 烘焙.py --list              # 看注册表

# 安装（源包 → dsh-pet 素材根）
$src = '12-源码照搬\外壳\petlive2d\桌宠动作包'
$dst = '12-源码照搬\引擎数据\.dsh\dsh-pet\pet'
New-Item -ItemType Directory -Force "$dst\fantuan-animation\webm"
Copy-Item "$src\fantuan-config.json" "$dst\fantuan-config.json" -Force
Copy-Item "$src\fantuan-avatar.png" "$dst\fantuan-avatar.png" -Force
Get-ChildItem "$src\webm\*.webm" | Copy-Item -Destination "$dst\fantuan-animation\webm" -Force

# 体检（DSH_HOME 指向引擎数据\.dsh）
$env:DSH_HOME = '12-源码照搬\引擎数据\.dsh'
node '12-源码照搬\引擎数据\.dsh\profiles\web\node_modules\dsh-pet\lib\standalone.js' --check
```

外壳侧开关：`12-源码照搬\外壳\data\pet\设置.json`

```json
"body": { "enabled": true, "kind": "dsh-pet", "pet": "fantuan", "base": "" }
```

> `设置.json` 是本机运行值（gitignored）。产品默认仍是 `enabled:false`；换机器后要重新打开，或在新机器上单独启用。

## 五、验收口径

- 41 段全部能解码，透明通道在 `libvpx-vp9` 解码下有效（角点 alpha=0，bbox 在舞台内）。
- 循环段首尾像素均差 < 1.1；`work_result` / `work_error` 为 0。
- dsh-pet `--check` 通过：条目 `fantuan`、桌面小窗 1 只、idle 3 个。
- `/thumb/fantuan/webm/<name>.webm` 全部 200，`Content-Type: video/webm`。
- **未验证**：真实桌面点击/拖拽/窗口移动的肉眼观感（需要整壳启动后在真实桌面看）；`turn_hop` 播完由 dsh-pet 翻转朝向时是否自然；Windows 透明窗在用户机器的显卡加速下是否保持 alpha。

## 六、已知限制

1. 桌面是烘焙视频，不是实时骨骼：头部角度硬夹在 ±4°，避免 9 层原画露下巴缝。
2. 眨眼/闭嘴是整脸补层，不是独立左右眼；要单眼 wink 需要另裁补丁或重新生图。
3. `events.balance` 在配置里保留 6 个占位名（余额关闭时不会播），避免 dsh-pet 校验整段 `animations` 非法。
4. dsh-pet 的 `turn` 语义是“播完翻转朝向”。`turn_hop` 结尾是正面，翻面后可能像瞬间镜像；如不接受，把 `pets[].fixedEnabled` 设 `true` 可关掉自动转向/移动，只保留原地动作。
5. 桌面 640×360，放大到 `size:600` 后角色约 188px 宽；再大就会看出视频噪点。
