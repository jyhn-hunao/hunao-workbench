# 桌宠 Live2D · 接口约定（2026-11-20）

> 状态：**已接入 `pet-live2d` 面板**（`@site:/petlive2d/`）。3D 渲染（three.js + GLB）已于同日移除，`pet3d\` 只剩概念图与表情包（QQ/微信的表情链路仍在用）。
> 当前形象：`模型\当前.json` 用 `layered` 演出层（原七层 PNG + 闭眼整脸层 + 闭嘴层）；默认外观与旧七层逐像素一致，眨眼/口型只切演出层透明度。

## 目录

| 路径 | 收什么 |
|---|---|
| `index.html` | 页面骨架 + 设置浮层 + 立绘兜底 |
| `app.js` | 加载模型、四态轮询、分层演出层眨眼/口型、容器呼吸、拖动/缩放/视线 |
| `vendor/` | PixiJS 6.5.10 + pixi-live2d-display 0.4.0（cubism4）+ Live2D Cubism Core |
| `模型/当前.json` | 模型清单（换模型只改这里） |
| `模型/正式/` | 正式 Cubism 模型（一个角色一个目录） |
| `模型/示例/` | 官方 Hiyori 示例，只在本机验证管线（`.gitignore` 已挡） |
| `立绘.png` | 模型没接入时的占位立绘（由 `概念\07-气氛图.png` 等比缩到 800×1200） |

## 工作台怎么显示

- 面板：`scenarios\pet.json` 的 `pet-live2d`，类型 `embed`，URL `@site:/petlive2d/`（端口不写死）。
- 静态路由：主进程把 `外壳\petlive2d\` 下的页面/模型/vendor 同源提供；只放行 `html/js/css/json/moc3/png/jpg/jpeg/webp/wav/mp3/ogg/txt/md`，路径做了防穿越，`..` 一律 404。
- 状态端点：`/petlive2d/state` → `{ state, sessionId, at }`，四态由 `外壳\桌宠状态.js` 从人格会话 transcript 判定（复用 `社交.js`，不新增第二套解析）。

## 四态

| 状态 | 来源 | 表现 |
|---|---|---|
| `idle` | 无人说话 | 循环动作组（`当前.json` 的 `motions.idle`） |
| `thinking` | `turn/start` 且无输出 | 有动作组就播；没有就叠歪头 + 半眼 |
| `speaking` | `assistant/message` 流式输出 | 原画默认张嘴，`mouthClosed` 补层按正弦开合做口型；头/眼不动 |
| `listening` | 最近 6 秒有真人输入 | 叠前倾 + 视线 |

## 交互

- 左键/单指拖动：平移；滚轮：缩放（0.5–2.5 倍）；双击不绑定，设置里有「缩放 · 复位」。
- 鼠标移动：`model.focus()` 让头和眼看向指针（模型不支持时自动跳过）。
- 单击（位移 < 5px）：播 `tapMotion` 动作组。
- 设置（右上角常驻文字入口）：Live2D 渲染开关 / 亮色背景 / 缩放复位 / 重新载入模型。开关落 `localStorage.petlive2d_render`、`petlive2d_theme`，会记住。

## 性能

- 默认限 30fps（`当前.json` 的 `fps` 可改）；页面不可见（最小化/切走）时停帧 + 停轮询，回来按开关恢复。
- 关掉渲染：`app.ticker.stop()` 停帧、清画布、停状态轮询；整页留「开启 Live2D 渲染」按钮，随时还原。
- 没有模型时：显示 `立绘.png` 占位（带呼吸动画），不跑 WebGL 模型，也不报错刷屏。
