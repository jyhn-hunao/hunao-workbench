# 记忆回响（dsh-memory-recall）

DSH 引擎插件：**每轮用户发言前**，把本场景的记忆注入成一条上下文，解决「记忆只在换会话时注入一次」的断片问题。

## 注入什么

- `场景私有记忆.md` 的 §〇 当前交接（≤1.6 KB）
- `_近期.md`（≤0.7 KB）
- `_索引.json` 里与本轮问题关键词命中的 3 条条目（标题 + 日期 + 绝对路径）
- 本场景的「拿不准就进待确认 / 收工」两行规则

总预算 ≤3 KB，超出截断。数据来源全部是场景记忆真源/派生，不新增存储。

## 场景怎么认

用 `agent.sessionId` 去 `外壳/scenarios/*.json` 的 `panels[].sessionId` 反查（唯一真源，缓存 30 秒）。查不到就跳过，不猜。

## 安装 / 回退

```powershell
node 12-源码照搬\工具\记忆回响.mjs --check          # 只读
node 12-源码照搬\工具\记忆回响.mjs --apply          # 装 + enforce
node 12-源码照搬\工具\记忆回响.mjs --mode shadow    # 只记日志、不注入（先观察）
node 12-源码照搬\工具\记忆回响.mjs --off            # 摘掉
```

⚠ 插件在引擎启动时加载，改完必须**重启整壳**（`12-源码照搬\启动.vbs`），⛔ 不要只重启引擎（token 会失效）。
